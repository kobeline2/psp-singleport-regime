## 1 本目 — 実験: 単一ポート浅水盆地の表面流レジーム

**問い**: 注水・排水時の表面流レジームは水深 (h/a) と流量でどう決まるか.

**中心的な結果** (2026-07-27 時点):
- 水深帯ごとのレジーム分類 (E, phi_lv, I_asym, I_circ/I_rot, I_unst).
- **流量が循環の向きを選択する**: inflow 12 ラン (4 日 x low/medium/high のブロック計画) で
  low は 4/4 が正, high は 4/4 が負, medium のみ 3 負 / 1 正. 同一日の中で low と high の
  符号が分かれるため, 装置セットアップや日差ではなく**流量に帰属する**.
- **medium は遷移域で双安定**: R0008 (4 日目) だけが逆符号. 深水帯 (B3/B4) の実測流量は
  R0007 と 1--4% しか違わないため, 同条件で結果が割れる真の分岐.
  ※ 引用する流量は必ず band を明示した値を使うこと (下記の注意を参照).
- ロックの強さ (|I_circ 平均|/std) が流量とともに単調増加 (low 1.0-7.0 → high 10.1-13.4).
- outflow は現状ノイズ床以下だが, **原因は PIV の画像対間隔 Δt の選定であり修正可能**
  (`doc/piv_conditions.md` §4). 再実験は不要で, 同じ元動画から対間隔を伸ばして
  再エクスポート・再 PIV すればよい. **投稿前に片付ける価値が最も高い項目**.

**この論文に属するもの**: 実験の全メトリクス, レジーム分類, 上記の流量-符号則と双安定性,
PIV の観測条件と限界.

**この論文に属さないもの**: CFD の検証, モデル間比較 (2 本目・3 本目へ).
**CFD の数値は本文に入れない** (上記「執筆順序」).

**投稿前に片付ける項目**:
1. outflow の Δt 再選定と再 PIV (`doc/piv_conditions.md` §8-2). 主要結果 3 本のうち 1 本が復活する.
2. `compute_actual_discharge` の平面積が水深に依らず一定という問題. 水位が導水路天端
   (h = a) より下では平面積が大きいため, 浅水帯の Q が過小評価される. 実測 q_actual が
   同一ラン内で B1 0.32 → B4 0.56 L/s と系統的に増加するのはこれが主因
   (s33 は既に A_below/A_above で処理済みなので, s31 側も揃える).
   なお q_actual は水位ロガーの 1 mm 量子化にも律速されているため, 流量を引用する箇所では
   遷移時間法 (Q = dV_band / T_band) を使う方が安全.
3. 原稿の残 TODO (`doc/piv_conditions.md` §6-7): トレーサ粒子の種類・粒径,
   Ω のポートマスク記述とコードの整合, methods.tex の eq:Iasym の絶対値.

## 2 本目 — 3D CFD: VOF による再現と, 再現できないもの

**問い**: 3D VOF (OpenFOAM interFoam) は実験のレジームをどこまで再現できるか. できない部分の原因は何か.

**中心的な結果** (2026-07-27 時点, `cfd/campaign.md` が詳細):
- 計算設定の確立: 六面体 72 万セル (鉛直 5 mm, バンド境界一致, 常時水没インレット) +
  設定 v1 (laminar + fixedValue 1 + nCorrectors 2 + PCG + cap 緩和) で 1000 s 充填 5.2 h, 質量 100%.
- 実験パイプラインへの接続 (`src/io/import_cfd_surface.m` → s30/s31/s32/s33) により,
  CFD と実験を同一の指標・同一の正規化で比較可能にした.
- **再現できたもの**: 浅水帯のレジーム形状, 充填履歴 (h(t) はメッシュ非依存で 0.2 s 以内),
  平均流の大きさ (無拡散の laminar で実験の 1.16 倍).
- **再現できなかったもの**: 循環のブランチ選択. CFD は左右対称の二渦に落ち,
  実験の「片壁に付着して盆地を満たす単一渦」にならない
  (偏り指数 ~0 vs 実験 ±0.24, 片符号の領域占有率 50-52% vs 実験 66%).
  深水帯のエネルギーは実測 Q² 正規化で 1.91-2.05 倍.
- **原因の切り分け (7/26-27 で書き換え)**: 気泡パージ・時間刻み・観測演算子・Ω マスクを棄却.
  さらに**摂動 3 種** (流入速度傾き P01 / 注入位置 P02 / ポート閉塞 P04) と
  **拡散 3 段階** (laminar / RANS RNGkε P06 / upwind P07) を系統的に振った結果:
  - 拡散は非定常性を**単調に治す** (変動 48.0 → 21.9 → 17.4%) が,
    **対称性は決して破らない** (偏り +0.076 / -0.036 / -0.021 で不動).
  - むしろ拡散は対称解を**安定化**し, 平均流を過大にする (1.16 → 2.3 → 3.9 倍).
  - これは浅水流の安定性理論の予測と一致する (Chen & Jirka 1997: 底面摩擦の増加は
    Re の減少と等価 → 分岐を抑える). **系が分岐の臨界より下にいる**という診断.
  - 臨界下では摂動は必ず減衰するので, P01/P02/P04 が「効いたが保持されない」のは当然の帰結.
- **先行研究との接続**: 「対称条件を課した数値解析は対称解しか返さない」は
  Constantinescu 1998 / Kantoush 2008a / Dewals 2008 が繰り返し報告している
  (`literature/review_master.tex` §7). 本研究の貢献は, これを**摂動と拡散を系統的に振って
  定量化し, 分岐図上に位置づけた**点にある. 失敗談ではない.

**未確定 (材料蓄積中)**:
- **D02 (inflow high) が最重要**. これまでの CFD は medium = 実験ですら態度が割れる遷移域
  でしか試していない. high は実験が 4/4 決定論的にロックし強度も 10 倍で, かつ充填が
  1.5 倍速いので壁時計 3.5 h と安い. ここでロックすれば 2 本目は
  「臨界上では再現し遷移域では再現しない」という**定量的な適用限界**の論文になる.
- P09 (細分メッシュ 288 万セル) — 対称二渦がメッシュ由来でないことの確認.
- 底面摩擦 / 鉛直解像度 — 唯一まだ触っていない物理軸. 浅水流の制御パラメータ.

**この論文に属するもの**: 計算設定の検証, メッシュ/スキーム/乱流モデルの感度,
実験との定量比較と乖離の帰属, VOF ならではの現象 (h/a≈1 の気泡パージ, 満管遷移).

**この論文に属さないもの**: 2D SWE との比較 (3 本目へ).

## 3 本目 — 2D/3D 比較 (共著, FH Münster)

**問い**: 深さ平均 2D (HEC-RAS SWE) と 3D VOF は, このレジーム選択問題をそれぞれどこまで
扱えるか. 両者の差は何に由来するか.

**材料**:
- 共同研究者 Weigert (2026) の HEC-RAS 2D Masterprojekt (メッシュ感度 P1-P14, solver 比較
  ELM/EM/LIA/DWE, inlet 表現 3 種, 3 流量 x 3 運転モードの再現).
- こちらの 3D CFD (2 本目の材料) と実験 (1 本目の材料).

**中心的な論点** (`doc/notes_2d3d_collaboration.md` に詳細):
- 2D SWE-ELM は**メッシュの数値誤差レベルの非対称だけで**単一渦がロックする.
  対称メッシュや breakline では直進. 低拡散の SWE-EM は直進のまま.
- 3D VOF は明示的な摂動 3 種を与えてもロックせず, 拡散を足すとむしろ対称が安定化する.
- h/a≈1 の満管⇔自由表面遷移は 2D では構造的に扱えない (3D VOF の担当領域).
- 排水は履歴依存 (2D では pump→turbine 連続計算でのみ実験と一致).

**枠組み (2026-07-27 に精密化)**: 当初の「自発的対称性の破れの感受性」は捨てず,
**「各モデルが分岐図のどこに位置するか」**に精密化する. 共通の 1 本の軸に並ぶ:
```
2D SWE-ELM : 臨界上 (メッシュの数値誤差だけでロック)
2D SWE-EM  : 臨界下 (直進)
3D VOF     : 臨界下 (種を与えても保持されず, 拡散を足すとさらに下がる)
実験       : 臨界上. しかも流量とともに臨界からの距離が増す (ロック強度 1.0 → 13.4)
```
これを 3 本目の中心図にする. 理論の錨は Dewals et al. 2008 の分岐パラメータ
R = ER·AR^(8/9) と Chen & Jirka 1997 の S--Re 平面 (`literature/review_master.tex` §7).

**解決済みだった設計課題**:
- ~~比較の公平性: 2D は数値的な種, 3D は物理的な種で種の種類が揃っていない~~
  → 3D 側で 3 種の異なる種がすべて効かないことが判明したため, **種の種類は論点でない**.
  差は種ではなく臨界からの距離にある.
- ~~1 本目で「流量が符号を決める」ため当初の枠組みは前提から見直しが必要~~
  → 流量依存はむしろ「臨界からの距離が流量とともに増す」として上の軸に自然に載る.

**未解決の矛盾**: Weigert の 2D では高拡散の ELM が付着し低拡散の EM が付着しなかったが,
3D では拡散を足すほど対称が安定化した (逆向き). ELM の付着が拡散ではなく
semi-Lagrangian の方向バイアス由来である可能性, または 2D SWE には鉛直構造がなく
分岐の性質が違う可能性. **先方への質問候補**.

**この論文に属するもの**: モデル階層の比較, 各モデルの適用限界, 実務的なモデル選択指針.
