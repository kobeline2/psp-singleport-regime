### 決定

1. **I-1 は控えめに書く．** Rehman 2015 と Hunt 2020 で支えられるのは控えの 1.1 にある範囲だけ．
   「再エネの拡大で運転の切替が増える」と「上池の堆砂が運用上の重要課題である」は，
   確認済みのメモに無い．それぞれ `\PHref{…}` にする．現地の計測（Müller 2018）は**下池**である．
2. **流れの向きは，運転の名前ではなく「貯水池へ吐出する／貯水池から吸い込む」で書く．**
   文献ごとに揚水・発電と吐出・吸込の対応が逆になる（下池の文献では発電が吐出）．
   本論文の inflow は「basin へ吐出」，outflow は「basin から吸込」である．
3. **Zhu et al. (2023) を「outflow（吸込）が非定常である」の根拠に使わない．**
   その「流出」は構造物から貯水池への吐出で，本論文の inflow の向きに当たる可能性が高い
   （bib の要旨による．確認済みの頁には向きの定義が無い）．使うなら
   「構造物から貯水池へ吐出するとき，構造物の近傍で瞬時流速の変動が大きい」と向きを明記して書き，
   `\jnote` で向きが未確認である旨を精査者に知らせる．
4. **I-3 は，原典が言う範囲に狭く書く．**
   - Fearn et al. (1990)\unverified：対称な急拡では非対称が symmetry-breaking bifurcation で生じる．
     装置の小さな欠陥が分岐を分断する（disconnected）．Reynolds 数を連続的に上げると常に同じ枝に入り，
     急に立ち上げたときは偏りが無い．**「pitchfork」「hysteresis」「slowly」「imperfect bifurcation」は
     この論文の語ではないので，この論文に帰さない．**
   - Cherdron et al. (1978)\unverified：形状の欠陥（段のずれ）または接近流の欠陥（片側の剥離）を
     与えると，短い再循環域の側が決まる．**欠陥の大きさは書かれていないので small と書かない．**
     控えの S10 はメモに無いので使わない．
   - Mullin et al. (2003)：閉じ込めた流路の低 Reynolds 数の流れである．浅い貯水池の文献として引かない．
     pitchfork の語と，微小な幾何の欠陥が分岐を大きく分断することは，このメモで支えられる．
   - Dewals et al. (2008)：浅い矩形貯水池の線形安定解析と幾何のパラメータ．
     「唯一の安定解析」とは書かない（手持ちの文献の中での話）．
   - Chen & Jirka (1997)：「流量を増すと摩擦の相対的な影響が下がり臨界から遠ざかる」は**メモに無い．書かない．**
     メモにあるのは，Reynolds 数が約 1000 を超えると粘性は効かず底面摩擦数が支配するということ．
   - Babarutsi et al. (1989)：片側の急拡である．対称性の破れの文献として引かない．
5. **I-4**：Müller (2012) の深い水槽での非対称の大きさと履歴の数値は控えの 1.2 にある．
   その偏向は overflow section による幾何の非対称が原因とされる（横か鉛直かはメモに無い）．
   **「outflow でも basin 全体に単一循環」という予備観察を独自性として書かない．**
6. **I-5 のギャップは「著者らの知る限り」で限定して書く．** 根拠はメモが黙っていることであり，
   原典が否定していることではない．書けるのは次の 4 点：
   (a) 浅い貯水池の研究は幾何を制御パラメータにし，流量はほぼ 1 条件である．
   (b) Reynolds 数を制御パラメータにした研究は，閉じ込めた流路の低 Reynolds 数の流れである．
   (c) 幾何を固定して流量だけを変え，反復を伴って，どちらの側を取るかを数えた報告は見当たらない．
       優先される側が制御パラメータとともに入れ替わるという報告も見当たらない．
   (d) 一つの可逆な開口をもつ浅い basin では調べられていない．
7. **I-6 に結果を書かない．** 目的と方法の概要まで．問いの順は，
   (i) 流量は循環の分枝の選択と固定の強さを支配するか（主），(ii) 吐出と吸込の非対称，
   (iii) 相対水深の役割，である．範囲の限定（流れだけを扱う，表面の計測，実機を参照した室内実験で
   厳密な相似模型ではない）を 1--2 文で書く．
8. **CFD に触れない．** 「将来の数値解析の検証データ」の一言までは書いてよい．
9. 分量は 900--1100 語．各段落の頭に主張を置く．

### 旧原稿から引き継がないもの（序論）

「静水開始」．outflow の単一循環の予備観察．上池の堆砂が重要課題という文と，その引用
（Müller 2012・2017，Jenzer Althaus 2015 はそうは言っていない）．Zhu を outflow の非定常に引くこと．
Mullin と Babarutsi を浅い貯水池の対称・非対称の文献に並べること．

### 決定

1. **実装のとおりに書く．** 旧原稿と実装が食い違う所は実装が正しい（控えの「Mismatches」）．
2. **開始の手順は `\PH`．** 収録は 24 run とも水位計の読み 30 mm（outflow は 100 mm）から始まる，
   とだけ書ける．その前に何をしたか（注水を始めた水位，静水を待ったか）は空欄．**「静水から」と書かない．**
   旧原稿の残留流の確認（5 %，5 分）は行った記録が無いので書かない．
3. **流量の設定はポンプの周波数．** バルブ開度と書かない．名目流量は名目の平面積 6.0 m^2 と
   水位変化率から決めた値であり，実測の平面積の値と等価として並べない．
4. **流量**：run 平均 `Q = A Δh / T`．水準ごとの値は，範囲（最小--最大）と，平均か中央値かを明記して書く
   （索引の 0.219 / 0.392 / 0.623 L/s は中央値．平均は 0.217 / 0.390 / 0.619）．
   **流量が run の中で一定であることの検証は inflow の 5 run（low 1，medium 4，high 0）だけ**である．
   そのとおり書く．outflow は別途の確認が要ると書く．下池の観測は，記録が無い項目を `\PH` にする．
   帯ごとの水位由来の流量，遷移時間法，「流量が水深で変わる」は書かない．
5. **水深**：主軸は時間比例の水深（収録の最初と最後の水位計の読みを結ぶ直線）．
   水位計の読みは h/a ~ 1 付近で直線から約 10 mm ずれる（inflow）．原因は水位計の読みと判断しているが，
   **水位計の span（端点の読みの正しさ）は未検証**で，run 平均流量の絶対値はこれを引き継ぐ．そのとおり書く．
   水深帯 B1--B4 は時間比例の水深で定義する．実装（`s31`）はまだ水位計の軸なので，
   その旨を `\jnote` に書く（本文には書かない）．
6. **水位計**：KEYENCE FR-S01，60 GHz のレーダー式，inlet の対面の壁際．「中心線上」は正本に無いので書かない．
7. **h = a の交絡**を 2.1 に書く：給水路は開水路で，断面の高さが port の高さと同じである．
   水位が a に達すると，port の潜没の完了と給水路の満管が同時に起こり，本装置では分離できない．
8. **PIV**：検証フィルタは 3 つ（標準偏差 6，局所中央値 3，相関係数 0.5）．画像対間隔は，inflow では
   名目流量との積が一定，outflow は全水準で共通．outflow の変位は 0.05--0.16 画素でサブピクセル精度の
   水準にあると，そのとおり書く．**outflow の再解析（画像対の取り直し）は未実施**なので，行ったことを書き，
   再解析の予定は `\jnote` に書く．トレーサ粒子と照明は `\PH`．サブピクセルの推定法は記録が数値コードだけなら `\PH`．
9. **ノイズ床**：2e-7 m^2 s^-2 は outflow low の pilot の run から取った値である．静水での計測とは書かない．
   0.06 画素との対応は合わない（outflow の画像対間隔では 0.076 画素）ので，画素の値を書くなら計算し直した値にする．
   時間平均による 1/sqrt(N) の低減は独立な場を仮定するので，断定しない．
10. **指標**は実装のとおり：`U_p` は**名目流量**から作る．`I_asym` は絶対値で，中線はベクトル格子の
    中点（y = 0.9853 m．port の軸 0.981 m から 4 mm）．渦度は中心差分で平滑なし．`I_unst` は帯内の
    トレンドを含む（そう明記する）．解析領域は格子の全域で port のマスクは無い．
11. **符号の向き**：`I_circ > 0` は解析の座標系（x は port の壁から basin の長手方向，y は横方向，
    図では y が上）で反時計回り．**実験室での実際の向き（カメラの像との対応）は未確認**なので，
    座標系の定義として書き，`\jnote` で未確認である旨を知らせる．
12. **分枝の集計**は 2.6：水深帯 B3 と B4 のフレームをまとめて，符号，ロック強度 `R_lock = |平均| / 標準偏差`，
    符号保持率．浅い帯を除く理由に「I_unst が 1 桁大きい」と書かない（時間比例の軸では 3--7 倍で，
    大半がトレンド）．理由は「h < a では噴流が自由表面に露出し，正味循環がまだ育っていない run がある」．
    第二の指標（エネルギーの偏る側）と，噴流の横ずれ（x ~ 1.0 m．実際の格子の列は x = 0.989 m）も定義する．
    横ずれは 12 run のうち 5 run でしか計算できていないので，その旨を `\jnote` に書く．
13. **検定**（`scripts/checks/branch_block_tests.py`）：日（ブロック）の中だけで並べ替えるものを主にする．
    (1) run 平均の `I_circ` を日ごとに順位づけた Page の傾向検定（正確，片側），
    (2) 符号についての層別の正確な順列検定（片側）．
    補助として，low と high の Fisher の正確検定．**方法には定義だけを書き，p 値は書かない**（結果の節に書く）．
    帰無仮説を正確に書く：(1)(2) は「1 日の中で 3 つの run の並びはどれも等しく起こる」．
14. **実機と縮尺**：実機を参照した室内実験で，厳密な相似模型ではない．参照した実機の値と，
    Froude 数から水準を決めたという記録は無い（水準は水位変化率で決めた）ので，書かないか `\PH`．
    Reynolds 数は水温が記録されていないので `\PH`（ν = 1.0e-6 m^2 s^-1 を仮定した暫定値を
    括弧で示してよいが，仮定と明記する）．
15. **表**は 2 枚：`tab:programme`（水準，名目流量，run 平均流量の範囲，run 数，日の配置，画像対間隔など）と
    `tab:piv`（PIV の設定）．水深帯は本文に書く（表にしない）．図は装置の概略図 1 枚の場所だけ取る
    （`figures/all.tex` の `\figplaceholder`，ラベル `fig:facility`．2.1 の担当が書く）．
16. 分量は 2.1--2.3 で 1100--1300 語，2.4--2.6 で 1100--1300 語．

### 旧原稿から引き継がないもの（方法）

「静水状態から開始」と残留流の確認．バルブ開度．「実際の流量は水深と没水状態で名目値からずれる」．
port 近傍を除いた解析領域．渦度の平滑化．ノイズ床が計測系の値であるという書き方．
「分枝は潜没の完了とともに定まる」．port の軸が y = 1.0 m という記述（実測は 0.981 m）．
