書式は自由. 日付を見出しにして追記していくと後で追いやすい.

> **【重要・2026-11-14 訂正】** このノートと cases.csv にある「渦核が壁に付着しない」「壁から 0.1 m 以内」「壁付着」は, 判定の根拠として**無効**である. 実験でも主渦の中心は盆地中央にあり, 壁に付くのは噴流. 詳しくは末尾の「2026-11-14 判定基準の訂正」.

## 台帳 cases.csv の書き方

列は小柴の `cfd/cases.csv` と同じ. 最低限これだけ埋める:

| 列 | 書くこと |
|---|---|
| case_id | `S` + 2 桁の通し番号 (S01, S02, ...) |
| status | planned → running → done (落ちたら failed, 途中でやめたら abandoned. 消さずに残す) |
| parent | 何から変えたか. テンプレートそのままなら `B03` |
| mesh | `hex_5mm_h013` (base) / `hex_fine_h013` (fine) / `hex_z2.5mm_h013` (zfine) |
| delta | 変えたこと 1 つ (例: `sigma 0.07 -> 0`) |
| purpose | **回す前に**: 何が起きたら成功か (例: 偏りの移動平均が ±0.2 を 300 s 以上保持) |
| wall_h, verdict | 終わったら: かかった時間, 結果 1-2 文 (動画を見た印象 + metrics.txt の数字) |

- 上下差は狙いどおり 16 % に戻った. それでも単一渦は戻らず, 中央の噴流と上下 2 渦になった. 偏りの向きも途中で変わる.
- よって S41 で単一渦が崩れた主因は流入の偏りではなく, 壁関数の変更 (Spalding) による壁の摩擦の増加 (約 2.8 倍).
- 言い換えると, S33 までの単一渦は, 壁の摩擦を小さく見積もる nutLowReWallFunction に支えられていた可能性が高い.
- ただし Spalding 則が正しい摩擦を与えているとも限らない. Spalding 則は平衡な壁乱流の速度分布を仮定しており, 噴流が吹き付ける浅い水槽の底では成り立たない場所がある. どちらの摩擦が正しいかは, 底面の境界層を解像した計算 (第 1 セルを y+ 1 程度に細かくする) でしか決められない.
- 実験では単一渦ができている (実際の摩擦の下で). CFD で摩擦を正しくしたときに単一渦が出ないなら, 渦を弱める別の要因 (数値散逸, 乱流モデルの渦粘性の過大, 流入条件) が残っている.
