## 2026-11-27 計画を立てる (計算なし)

### 方針 (ユーザー決定)

- inflow では単一渦を作るために流入を工夫する (yaw) が, outflow は単一渦ができないので片寄りは与えない.
- 壁関数と導水路の形は inflow と同じにする. inflow の逆向きに流出させる.

### 実験の outflow で分かっていること (出典は cfd-campaign ブランチ)

- 形: 盆地全体からポートへ向かう, 左右ほぼ対称の収束流. 偏向・再循環・回転はない. I_rot 0.002-0.007 (inflow 0.06-0.12 の約 1/20), I_circ ≈ 0 (`paper/2026_journal_Shonai/sections/results.tex` の outflow の節).
- 強さ: 表面の E は同じ流量の inflow より約 3 桁小さい. phi_lv は全条件で 1.000 に飽和 (帯平均の表面流速は U_p の 0.35-2.2 %).
- 非定常性: 解像できた high の B1 (SNR 約 37) で I_unst = 0.76. inflow の最大 (B1 の 0.35-0.40) の約 2 倍.
- PIV の制約: 解像できているのは high の B1 だけ (high B4 は SNR 約 6). low/medium は画像対間隔 Δt が 333.7 ms 固定で変位 0.05-0.16 px のためノイズ床. 元動画から Δt を選び直して再 PIV すれば直る (再実験不要. `doc/piv_conditions.md` §3-4). 論文 1 側の作業.
- 流量: 各 run でほぼ一定. ラン平均は公称の 0.78-1.00 倍 (`doc/qdip_jet_check.md` §0). 一定の Q を与える境界条件でよい.
- ポートの天端が水面から出る深さ (水位計で 50 mm 前後, 時間比例の深さで 53 mm 前後) で表面流が急に強まる (同上).
- 予備観察で見えた「outflow の単一循環」は, 先行する inflow の残留循環だった可能性が高い. ただし実験の開始手順 (100 mm の静水から始めたか) は未確認で, 論文 1 でも「静水開始」とは書かない扱い (`paper/README.md`).
- 2D (HEC-RAS) の知見: 排水は履歴依存で, 単独の排水計算は無構造, 注水→排水の連続計算でのみ実験と一致した. 2D は h/a ≈ 1 (排水時 5-6 cm) で振動的に破綻する (`doc/notes_2d3d_collaboration.md` §3).

### 目的

1. 同じ形状・同じ設定で, inflow と outflow のレジームの非対称を CFD で再現する (研究課題 1).
2. 実験で解像できない帯 (深い帯, low/medium) を CFD で補う (予測).
3. inflow の残留循環が outflow に持ち越されるかを確かめる (予備観察の解釈).

### inflow の基準から引き継ぐもの・変えるもの

- そのまま: 実寸の水槽 (2.952 x 1.962 m), 導水路の形, 壁関数, 乱流モデル (いまは k-omega SST), 格子, p_rgh 許容値 1e-9, sigma 0. いずれも inflow で確定した値に合わせる.
- 外す: 流入の yaw.
- 変える: 導水路上流端の境界条件. いまの流入 (下 4 層 44 面, `variableHeightFlowRateInletVelocity`, alpha `fixedValue 1`) の符号反転は設計外 (小柴の E 系列のメモ). 候補は水相の流量 -Q を抜く `flowRateOutletVelocity` (水相指定ができるか v2412 で確認), または `outletPhaseMeanVelocity`. alpha は `inletOutlet`. 抜く面を下 20 mm のままにするか導水路の全断面にするかも試運転で決める.
- 乱流の初期値: 静水から始めると流入の k (2e-4) に当たるものがない. 水槽の初期の k, omega は小さい値にする (値は試運転で決める).
- 難所: h < a (B1) で導水路が満管から自由水面に変わり, 抜く面に空気が来る.

### 壁関数を inflow と同じにしてよいか (ユーザーの質問への回答)

同じでよい. 理由:

- 水槽の壁: inflow の y+ は中央値 5-9 (S30, 2026-11-16 の節. y+ = sqrt(|U| y / nu)). outflow の水槽内の流速は約 30 分の 1 (E が約 3 桁小さい) なので, y+ は sqrt(1/30) で約 1-2 になり粘性底層に入る. ここでは nutLowRe も Spalding も nut ≈ 0 の線形則になり, 差はほぼ出ない.
- 導水路: 同じ Q が同じ断面を通るので流速は inflow と同程度で, 壁関数による差 (inflow で導水路の底面摩擦が 1.8 倍違った) は残る. ただし outflow では導水路は水槽の下流にあり, inflow のように噴流を作らない. 流量は境界条件で与えるので, 導水路の摩擦は水槽の流れにほとんど効かないと考えられる (未確認).
- 比較の都合: inflow と outflow を同じ設定にしておけば, 違いを流れの向きだけに帰着できる.
- 確認: 試運転 (O01) と本計算 (O02) で水槽と導水路の y+ を出し, 上の見積もりを確かめる.

### 成功の基準 (O02)

- 実験どおり, 回転のない対称な収束流. 静水から始めて回転が出たら実験と食い違う.
- 評価は E, I_asym, I_rot, phi_lv, I_unst で行い, 実験と同じパイプライン (`s33`) を通す. `surface_movie.py` の bias / dominant は inflow の偏向を見る指標なので主には使わない.
- 実験側の比較相手: いまは high の B1 だけ. low/medium は再 PIV の後.
