# CFD キャンペーン計画

シリーズ = 「Excel の 1 シート」に相当する, 目的を共有するケース群.
個々のケースの行は `cases.csv` が正本. ここには各シリーズの目的・前提・合格基準・決定だけを書く.
シリーズは番号順に消化するが, B (メッシュ作成) は A と並行で準備してよい.

進め方の原則: 変更は 1 ケース 1 種類. 判定基準を先に書く. 結果が出たら「決定」欄を埋めてから次へ.

## 導水路の形状を実験者に確認 — モデルは正しく, しかし h/a = 1 に交絡がある — 2026-07-31

**確認できたこと (実験者への照会)**
- 給水系は**開水路** (自由表面を持つ). 圧力管ではない.
- 断面高さは **55 mm = ポート高 a と厳密に同じ**.

**帰結 1: CFD の導水路モデルは実物と一致している (変更不要)**
現行メッシュは 0.6 m x 0.11 m x 0.055 m, 天端は壁, 上流端の下 20 mm のみ流入という構成で,
高さについては実物と厳密に一致する. 7/31 に一時的に立てた
「満管遷移は導水路天端を実物より低く作ったことによる人工物ではないか」という疑いは**棄却**.
→ **満管遷移は実現象**であり, 2 本目に「VOF でなければ扱えない現象」として書いてよい.
2D SWE が構造的に扱えない領域という 3 本目の論点も, 前提が実物で裏づけられた.

**帰結 2: 問題2 (エネルギー過剰) の容疑者にはならない**
満管が実物にもある以上, これを問題2 の原因にはできない. 深水帯の E 過剰 (1.9-2.0倍) は
依然として未解明のまま残る. 7/31 に挙げた容疑は取り下げる.

**帰結 3: [重要] h/a = 1 で 2 つの現象が同時に起きる — 分離不能な交絡**
導水路高 = ポート高なので, 水位が a に達した瞬間に
```
(1) ポートが水没する            (水槽側の幾何学的遷移)
(2) 給水路が満管になる          (給水系の水理学的遷移)
```
が**必ず同時に起きる**. これは装置の設計上そうなっており, 実験でも CFD でも分離できない.
→ **h/a = 1 前後で指標が変化しても, どちらの機構によるものか本装置では判定できない.**
1 本目・2 本目とも, h/a ≈ 1 の遷移を論じる箇所ではこの交絡を明記すること.
分離するには給水路高を変えた装置改造が要る (将来の課題).

**残る数値的な問題 (幾何とは無関係)**
満管後の導水路は界面のない全水領域になり, そこで MULES の行き過ぎが蓄積して
alpha が膨張する (平均 1.026 @ t=1000, 最大 1.09). B03 の質量欠損 -0.51% はこれが全て.
A13 で MULESCorr 一式を試したが成長率は不変だった. 幾何が正しい以上, これは
**数値側で対処すべき残件**である. ただし終端水位誤差 -0.5 mm は許容範囲で,
指標への影響は無視できるため優先度は低い.

## P09 (細分メッシュ) が決着をつけた — 対称二渦はメッシュ由来ではない — 2026-07-30

P09 = B03 と設定を厳密に同一 (laminar + linearUpwind) にして**メッシュだけ 4 倍**にしたラン
(72 万 → 288 万セル, 41.3 h). P08 = 同じく B03 の設定から**移流を純中心差分に変えただけ**
(数値散逸ゼロ, `Gauss linear` が退避なしで完走. VOF での非有界化は起きなかった).

| case | 変動% | 偏り | 支配符号% | 最大塊% | **ロック強度** |
|---|---|---|---|---|---|
| **P09 細分 288万** | 45.7 | **-0.054** | **53.1** | 39.8 | **0.31** |
| **P08 中心差分 (散逸0)** | 19.6 | **-0.065** | **53.6** | 44.2 | **1.77** |
| B03 基準 72万 | 48.0 | +0.076 | 50.3 | 35.7 | 0.67 |
| P07 upwind (散逸最大) | 17.4 | -0.021 | 50.1 | 44.9 | 0.90 |
| P02 非対称注入 | 10.4 | -0.040 | 54.3 | 50.9 | 1.31 |
| **実験 R0006** | **5.7** | **+0.249** | **66.0** | 64.5 | **15.18** |
| **実験 R0008** | **4.7** | **-0.244** | **66.3** | 64.1 | **12.47** |

**(1) メッシュ独立性が確認された — これが本キャンペーンの決着**
セルを 4 倍にしても渦度マップは B03 と同じ対称二渦 (y=1.0 に直線境界, ジェットは中心線を直進).
支配符号 53.1% は B03 の 50.3% からほぼ動かず, 実験の 66% に遠い. ロック強度に至っては
0.67 → **0.31 と下がった**. 表面点数が 32,599 → 124,797 (3.83 倍) で細分は確かに効いている.
→ **対称二渦は粗メッシュのアーティファクトではない.** 2 本目の中心的主張が確定した.

**(2) 数値粘性仮説も低散逸側から棄却**
P08 は数値散逸を原理的にゼロにしたが, 偏り -0.065 は B03 の +0.076 と同程度で,
ロック 1.77 は実験の 12-15 に 1 桁足りない. 「粗格子の数値粘性が分岐を抑えている」は
**メッシュ側 (P09) からも スキーム側 (P08) からも否定された**.

**(3) [撤回] 拡散軸は単調ではなかった**
P07 の後に「拡散は非定常性を単調に治す」と書いたが誤り. 変動を散逸の順に並べると
```
linear (散逸0)      19.6%
linearUpwind (中間) 48.0%   ← 最も脈動する
RANS (中間+nut)     21.9%
upwind (最大)       17.4%
```
**両端が定常で中間が脈動する**という非単調な関係で, 機構は説明できていない.
撤回すべきは「単調」の部分だけで, **対称性については全 4 段階で完全に平坦**
(偏り -0.065 〜 +0.076) であり主結論は揺るがない.

**(4) 全軸を尽くした — 2 本目の主張はこれで固まる**

| 振った軸 | 水準 | 偏り指数の範囲 | ロック強度の範囲 |
|---|---|---|---|
| 種 | 3 種 (速度傾き / 注入位置 / ポート閉塞) | -0.040 〜 +0.076 | 0.67 〜 1.31 |
| 拡散 | 4 段階 (linear / linearUpwind / RANS / upwind) | -0.065 〜 +0.076 | 0.67 〜 1.77 |
| メッシュ | 3 種 (hex 72万 / prism 181万 / hex 288万) | -0.054 〜 +0.076 | 0.31 〜 0.67 |
| 流量 | 2 水準 (medium / high) | -0.026 〜 +0.076 | 0.67 〜 0.99 |
| 乱流モデル | 3 種 (laminar / WALE / RANS) | -0.046 〜 +0.076 | — |
| **実験** | — | **±0.24** | **12 〜 15** |

**どの軸をどう振っても偏りは ±0.08 の内側に留まり, ロック強度は実験の 1/10 以下**.
これは「もう少しで届く」ではなく「**構造的に別の解を選んでいる**」ことの定量的な証明である.

**(5) 唯一残った未検証の軸: 底面摩擦 / 鉛直解像度**
z 方向は全ラン 5 mm 固定で一度も触っていない. 浅水流の制御パラメータは底面摩擦であり
(Chen & Jirka 1997), 水深 30-100 mm に対し 6-20 セルは境界層としては際どい.
2 本目を書き始める前に 1 本だけ回す価値がある.

## D02 (high) も失敗 — CFD と実験は「同じ軸の遠近」ではなく別の枝にいる — 2026-07-28

摂動なしで流量だけ high (0.75 L/s) に上げたラン. 実験が 4/4 決定論的にロックする条件なので,
「CFD が失敗するのは medium が遷移域だから」という仮説の直接検証だった.
水深を揃えるため窓は **t = 323-633** (他ケースの 485-950 と同じ h = 0.060-0.098 m).

| case | 変動% | 偏り | 支配符号% | I_circ | **ロック強度** |
|---|---|---|---|---|---|
| **D02 high (摂動なし)** | 42.1 | -0.026 | 52.9 | **+0.00216** | **0.99** |
| B03 medium (摂動なし) | 48.0 | +0.076 | 50.3 | +0.00189 | 0.67 |
| P02 medium (非対称注入) | 10.4 | -0.040 | 54.3 | +0.00209 | 1.31 |
| 実験 R0009 high | | | | -0.00981 | **11.71** |
| 実験 R0010 high | | | | -0.00984 | **12.42** |
| 実験 R0011 high | | | | -0.00750 | **10.09** |
| 実験 R0012 high | | | | -0.00950 | **13.40** |
| 実験 R0006 medium | | | | -0.00780 | 10.55 |

**(1) 明確な失敗**: ロック強度 0.99 に対し実験 high は 10.09-13.40 で **1 桁違う**.
符号も逆で, CFD が +0.00216 なのに実験 high は 4 本すべて負.
渦度マップも対称二渦 (y=1.0 に直線境界, ジェットは中心線を直進) で,
B03/P04/P05/P06/P07 と同一トポロジー. **流量を上げても何も動かない.**

**(2) 仮説「medium が遷移域だから失敗する」を棄却.** 実験が最も決定論的にロックする条件でも
再現しない. 摂動 3 種 x 拡散 4 段階 x 流量 2 水準のすべてで壁付着は出ていない.

**(3) 重要な定量的所見 — CFD の I_circ 平均は「ロック」ではなく「残差ノイズ」**
```
CFD :  medium 0.67 -> high 0.99   (1.48倍.  流量1.5倍にほぼ比例)
実験:  medium 10.55 -> high 11.7-13.4 (1.1-1.3倍.  既に飽和)
```
CFD のロック強度は**強制振幅に比例して増えるだけ**で, これはロックしていない系の
残差の振る舞いである. 一方実験は medium で既に ~10 に飽和しており, ロック枝の上にいる.
→ **両者は同じ軸上の遠近ではなく, 別の枝にいる.** 流量を 1.5 倍にして 1.5 倍動くのだから,
実験に届かせるには流量 10 倍が要る計算になり, 閾値越えの話ではない.

**(4) 副産物**: P09 (細分メッシュ) を medium のまま回してよいことが確定した.
流量は効かないので条件を変える必要がない. D02 を P09 の前に置いた判断は,
期待した向きではないが目的は果たした.

## [訂正] P05 が「P02 は速度2倍の交絡」を否定 — 非対称注入だけが正しいトポロジーを作る — 2026-07-27

P05 = 流入面を下2層 22 面に絞り, **y 方向は 11 セル全部残して厳密に左右対称のまま
流入速度だけを 2 倍**にした対照ラン. 7/26 に「P02 で脈動が止まったのは非対称のおかげでなく
流入速度 2 倍でジェットが硬くなったため」と書いた仮説の直接検証.

**結果は逆だった**: 変動 59.9% で, 無摂動 B03 の 48.0% より**増えた**.
渦度マップも対称二渦 (B03/P04/P06/P07 と同じトポロジー) で, ジェットは中心線を直進する.
→ **速度2倍は脈動を止めない. むしろ悪化させる.**
よって **P02 の定常化は非対称注入そのものの効果**であり, 7/26 の「交絡」判断は撤回する.

**全8ケースを流入形状で並べ直すと像が変わる** (深水帯 485-950)

| case | 流入 | 拡散 | 変動% | 偏り | 支配符号% | 最大塊% | 平均場の構造 |
|---|---|---|---|---|---|---|---|
| B03 | 対称 44面 | laminar | 48.0 | +0.076 | 50.3 | 35.7 | 脈動・分裂 |
| P05 | 対称 22面 (2倍速) | laminar | **59.9** | +0.063 | 51.6 | 38.6 | 脈動・二渦 |
| P04 | ほぼ対称 (1/11閉塞) | laminar | 45.5 | -0.010 | 50.4 | 38.6 | 二渦 |
| P06 | 対称 44面 | RANS | 21.9 | -0.036 | 51.7 | 38.7 | 定常二渦 |
| P07 | 対称 44面 | upwind | 17.4 | -0.021 | 50.1 | 44.9 | 定常二渦 |
| **P02** | **非対称 20面** | laminar | **10.4** | -0.040 | **54.3** | **50.9** | **定常・単一渦** |
| P03 | 非対称 20面 | WALE | 13.7 | -0.046 | — | — | 定常・単一渦 |
| **実験** | — | — | **5.7** | **+0.249** | **66.0** | **64.5** | **付着・単一渦** |

**(1) 定常化には 2 つの別々の経路があり, 行き先が違う**
```
拡散を足す      → 定常だが「対称二渦」  (P06, P07)
非対称に注入する → 定常で「単一渦」      (P02, P03)  ← 実験と同じトポロジー
```
拡散は変動を減らすが渦を 2 つのままにする. 非対称注入だけが渦を 1 つにする.

**(2) P02 は実は全ケース中もっとも実験に近い.** 変動 10.4% (実験 5.7%), 支配符号 54.3%
(実験 66.0%), 最大塊 50.9% (実験 64.5%) の 3 指標で最良. 唯一届いていないのが偏り指数で,
これは渦がコンパクトで盆地中央に留まり壁に付着しないため.
→ 7/26 に「摂動は完全に整流されていた」と書いたのは**言い過ぎ**だった. 偏り指数は動かないが
トポロジーは変わっている. 指標 1 つで判定していた誤り (組織化度のときと同型の誤り).

**(3) 摂動軸を閉じたのは早すぎた.** 正しい要約は「種は効く. ただし効き方が部分的」:
- 効くもの: 大きな注入非対称 (流入面積の半分) → 脈動が止まり単一渦になる
- 効かないもの: 小さな種 (P01 速度 5%, P04 ポート面積 1/11) → 何も起きない
- まだ出ていないもの: 渦が盆地を満たすこと (壁付着)
→ 差は**種の位置ではなく大きさ**. P04 で「位置」に帰属させたのは誤りで,
P02 (上流 0.6 m) が効いて P04 (整流距離ゼロ) が効かないのは, 前者が面積の 1/2,
後者が 1/11 だからと読む方が整合する.

**(4) 次に効きそうな設計**: P02 の非対称を保ったまま渦を外へ広げる方向.
D02 (high 流量) の結果と合わせて判断する — 実験はロック強度が流量とともに 10 倍以上
増すので, 非対称注入 x high 流量の組み合わせが最有力候補になる可能性がある.

## P07 が拡散軸を閉じた — 拡散は非定常性を単調に治し, 対称性を決して破らない — 2026-07-27

P06 後の反転予測 (「upwind はさらに対称・定常になるはず」) が的中した. 拡散軸は単調である.

| case | 拡散 | 変動% | 偏り | 支配符号% | 最大塊% | 平均場の構造 |
|---|---|---|---|---|---|---|
| B03 laminar | 最小 | **48.0** | **+0.076** | 50.3 | 35.7 | 分裂・脈動 |
| P06 RANS | 中 | 21.9 | -0.036 | 51.7 | 38.7 | 綺麗な対称二渦 |
| P07 upwind | 最大 | **17.4** | -0.021 | **50.1** | 44.9 | 極めて綺麗な対称二渦 |
| **実験** | — | **5.7** | **+0.249** | **66.0** | 64.5 | **単一の大循環** |

P07 の渦度マップ (`local/results/figures/P07_vorticity.png`) は上下半分を埋める巨大な
ほぼ矩形の二渦で, y=1.0 にカミソリのような直線境界が立ち, ジェットが中心線を遠壁まで直進する.
**全ケース中もっとも対称 (支配符号 50.1% = 完全均衡) かつもっとも定常.**

**(1) 拡散仮説は決着 (棄却)**: 拡散を増やすと変動は単調に減る (48.0 → 21.9 → 17.4) が,
偏りは +0.076 / -0.036 / -0.021 と一貫してゼロ近傍のままで, 実験の ±0.24 に近づく気配がない.
支配符号面積も 50-52% で実験の 66% に届かない. **拡散は非定常性を治すが対称性は破らない.**

**(2) しかも拡散は別の誤差を作る (重要)**

| case | E_inst | 平均流 | 実験比 (平均流) |
|---|---|---|---|
| 実験 | 0.000409 | 0.000386 | — |
| B03 laminar | 0.000864 | 0.000449 | **1.16x** |
| P06 RANS | 0.001137 | 0.000888 | 2.3x |
| P07 upwind | 0.001835 | 0.001516 | 3.9x |

**平均流がもっとも実験に近いのは無拡散の B03 (1.16x)** で, 拡散を足すほど過大になる.
機構: 脈動状態は蛇行にエネルギーを散らすが, 定常な対称二渦はコンパクトで速い循環を
2 つ作るので運動エネルギーが上がる. → 拡散は**変動誤差 (48→17%) と引き換えに
平均流誤差 (1.16x→3.9x) を買っている**. 単純な改善ではない.

**(3) 診断の書き換え: これはエネルギーの誤りではなく「トポロジー」の誤り**
```
CFD :  対称二渦ブランチを選ぶ (コンパクトで速い渦が2つ, 打ち消し合う)
実験:  付着単一渦ブランチを選ぶ (盆地を満たす大きく遅い渦が1つ)
```
同じ運動量入力に対し, 実験は盆地全体に広がるので遅く (平均流 0.000386),
CFD は 2 つのコンパクトな渦に集中するので速い. 支配符号 66% vs 50% と
最大塊 64% vs 45% はこの「広がり」の差そのもの.

**(4) 次の方向は逆転する**: 3 種の種 (P01/P02/P04) も分布非対称メッシュ (B05) も効かず,
拡散はむしろ分岐を抑える. 残る第一候補は **粗格子の数値粘性が既に過剰で, 分岐に必要な
実効レイノルズ数に届いていない**こと. 最小拡散の B03 が 3 つの中で最大の |偏り| 0.076 を
持つことも, 弱いが同じ向きを指す.
- **安価な確認 (P08)**: `div(rhoPhi,U)` を `Gauss linear` (純中心差分, 最小散逸) か
  `Gauss LUST grad(U)` に. 1 行, 約 5 h. 拡散軸の低い側を埋めて単調性を確認する.
  偏りが 0.076 より大きくなれば方向確定.
- **本命 (要判断)**: x-y を 10-15 mm から半分に細分 (約 290 万セル, 壁時計 25-30 h).
  P08 で方向が確認できてから投じるのが妥当.
- 併走候補: 3D 効果 (底面境界層の二次流れ). 現状 z 5 mm で水深 30-100 mm = 6-20 セルは
  境界層としては際どい.

## エネルギー過剰の正体 — 平均流と変動への分解 (2026-07-25 確定)

ユーザーの指摘 (「瞬時値は大きくも小さくもなる. カイ二乗のバイアスは自由度で消えるのでは」)
を機に観測演算子の議論を精密化し, ついでに E を平均流と変動に分解したところ, **診断が
『E が 2.2 倍』から『変動が 9-32 倍』へ書き換わった**.

**(1) 観測演算子の理屈 (訂正)**: 「瞬時値だから大きい」は誤り. 正しくは**2乗と平均の順序**:
CFD は `<u²>`, PIV は `<u>²` を計算しており, Jensen の不等式から常に `<u>² ≤ <u²>`.
レイノルズ分解で `E_cfd - E_piv = <u'²> - <(Δt平均した u')²> ≥ 0` — 各点で成立する系統差なので
多点平均では消えない (自由度で消えるのは推定バイアスであって, この量の差ではない).
ただし大きさは**変動スペクトル次第**で, Δt より長い時間スケールの変動は削れない.

**(2) 実測 (B03 深水帯 485-950)**: 変動成分は E の 48% もあるが,
**5 秒ペア平均でも E は 1.2% しか落ちない** (0.000864 → 0.000854) — 変動が 300-370 s の
遅い脈動にあるため. PIV の Δt=0.1 s はさらに 1/50 なので実質ゼロ.
→ **時間の観測演算子も棄却** (空間フィルタの ~4% に続き). 観測演算子は E 過剰の原因ではない.
なお逆向きの効果として PIV ノイズは E を上振れさせるが, E_noise 2e-7 / E 4e-4 = 0.05% で無視可.

**(3) 副産物 — 診断のシャープ化 (重要)**:

      run          E_inst     E_tmean(平均流)  変動成分     変動%
      実験 R0005 B3 0.000433   0.000412        0.000021     4.9%
      実験 R0006 B3 0.000434   0.000407        0.000027     6.2%
      実験 R0007 B3 0.000351   0.000304        0.000047    13.5%  (対称repは変動多め)
      実験 R0008 B3 0.000381   0.000362        0.000018     4.8%
      CFD B03 深水  0.000864   0.000449        0.000415    48.0%

  - **平均流: CFD 0.000449 vs 実験 0.000304-0.000412 = 1.1-1.5 倍 (ほぼ正しい)**
  - **変動: CFD 0.000415 vs 実験 0.000013-0.000047 = 9-32 倍 (ここが全て)**
  - → 「CFD は一様にエネルギー過剰」ではなく, **平均循環の強さはほぼ正しく, 過剰分は
    まるごと『あるべきでない遅い脈動』**. I_unst が 8-14 倍だったことと同じ現象の
    エネルギー単位での表現. 統合仮説 (散逸を欠くから落ち着けず脈動する) の直接的裏付け.
  - 論文での言い方: E の絶対値だけでなく **E = E_mean + E_fluct の分解で示す**と,
    モデルの欠陥が「循環が強すぎる」ではなく「定常化できない」ことが一目で伝わる.

  → 組織化しないと平均流も弱い. ロックrep (0.000407-0.000412) との差が組織化の価値を示す.

## 時間の観測演算子も棄却 (実測, 2026-07-26)

ユーザー指摘により機構を訂正: 「CFD は瞬時値だから E が大きい」は誤り (瞬時値は小さくもなる).
正しくは**2乗と平均の順序** — PIV は Δt 平均してから2乗, CFD は2乗してから平均.
Jensen の不等式より <u>² ≤ <u²> で**常に片方向**の系統差 (各点で成立するので多点平均では消えない.
標本数で消えるのは推定バイアスであって別物).
ただし大きさは変動スペクトル依存: 実測 (B03深水) では

```
Δt=5s のペア平均 → E は瞬時の 98.8% (1.2%しか落ちない)
Δt=465s (バンド全体) → 52.0% (変動48%が全部落ちる)
```

変動は 300-370s の遅い脈動にあるため, **PIV の Δt=0.1s では実質ゼロ**.
→ 空間フィルタ (~4%) に続き時間フィルタも棄却. **観測演算子は E 過剰の原因ではない**.
逆向きの効果 (PIV ノイズが E を上振れ) は E_noise 2e-7 / E 4e-4 = 0.05% で無視可.

## 対称性破れの「種」の条件 — 2026-07-25 確定

4 ケースの比較から, **破れの種は流入部に要り, 系統的でなければならない**と判明:

| ケース | 流入部の対称性 | 領域全体 | 結果 |
|---|---|---|---|
| Weigert 2D 非対称メッシュ | **非対称** (culvert縁のセル重なり差) | 非対称 | **ロック** |
| B05 三角柱 (1.81M) | **完全対称 (鏡像一致 100.0%)** | 強い非対称 (鏡像一致 3.1%) | ロックせず |
| B03/P01 六面体 | 完全対称 (y: 63/11/63 セル, grading 1) | 完全対称 | ロックせず |
| P02 幾何摂動 | **強い非対称** (上20面のみ注入, 下24面は壁) | 対称 | **ロック (早期)** |

- 実測: B05 の inletOutlet 44面は 下20/上20, 平均 |y-1| が 0.03000/0.03000 で 5桁一致,
  鏡像一致率 100.0%. topoSet の座標基準手術 (z<0.02) が押し出し方向の規則性を保ったため.
  一方 B05 の全節点は鏡像一致率 3.1% = 領域全体では強く非対称.
- **結論**: 領域内のランダム/分散した非対称は効かない (対称な不安定固定点の周りで揺らすだけ).
  破れには**運動量注入点での一貫した持続的バイアス**が要る.
- 効く種 = 流入部の幾何・離散化の非対称. 効かない = 領域全体のメッシュ非対称,
  弱い方向バイアス (P01 の 5% 横速度: 導水路 0.6m で整流されて消える), 一過性の初期擾乱.
- **実験側への含意**: 実験でロックが起きる以上, 実験の非対称も流入部にあるはず.
  → 学生への確認項目: 導水路の加工精度, ポート内 3 枚の仕切り板の左右対称性,
  ホース接続の偏り, 流入口近傍の水路壁の仕上がり.
- **皮肉な教訓 (論文に書ける)**: 数値的に清潔な完全対称メッシュ (B01) を作ったことで,
  実験が持つ物理的非対称を意図せず排除していた. Weigert の粗い非対称メッシュは
  数値誤差という形で偶然「実験の不完全さ」を模擬していた.
  → **多安定系では「良いメッシュ」が物理の再現を妨げうる**.

**7/24 深水帯 機構の確定 — A15(WALE) と B05(三角柱) の判定 + R0005/7 の場:**
乖離は**2つの独立な問題**に切り分けられた:

*問題1: 組織化/対称性 — 解明 (物理として理解).* CFD は対称レジームに落ち込む.
- **A15 (WALE) 両軸で効かず**: B3窓で E平均 0.00118 (laminar 0.00115とほぼ同), I_circ |平均|/std 0.22
  (対称のまま). 散逸を足しても E 下がらず対称性も破れない → **散逸仮説(a)は棄却方向**.
  (限界: 窓182s<振動周期, 対称初期条件からの再開. 粗格子で ν_t~ν_num).
- **B05 (三角柱) = B03 (六面体)**: 両方 弱組織化/対称 (|I_circ平均|/std 0.74 vs 0.60, 正%77 vs 71,
  どちらも強ロックせず). → **対称性破れの失敗はメッシュ非依存 = laminar の性質**.
- **R0005/R0007 の場で multistability を視覚確認**: R0005/R0006 = 上壁付着・単一渦 (ロック),
  R0008 = 反対壁ロック, **R0007 = 中心線ジェット+対称二渦 = CFD と同一トポロジー**.
  medium 4反復 = ロック3 + 対称1(R0007). **CFD は実験でも実現する対称branch (R0007) を捉えている**
  = 非物理でなく, 多安定系の1つの状態. 支配的なロックbranch再現には**明示的な対称性破れ摂動が必須**.

*問題2: エネルギー — 未解明 (別問題として残る).* 対称branch同士でも CFD が過剰.
- **CFD の E は R0007 (実験の対称rep) の 2-3倍** (B3: 3.1x, B4: 2.0x). 対称性を揃えても残る.
  WALE でも下がらない. → 対称性とは独立の第2の乖離.
- **B05 で判明 (7/24 追検証): E はメッシュ依存**. バンド平均E (位相を均した, 両メッシュ同一手法,
  B03側は登録C0001と5%以内で検証済) で B05三角柱(1.81M) が B03六面体(0.72M) の最大2倍
  (B1 1.07, B2 2.05, B3 1.14, B4 2.02, 全て三角柱が高い=系統的). 細かいメッシュほど数値散逸が
  減り E 上昇 = ILES の散逸不足が解像度依存で実在. → **問題2の第一容疑を観測演算子から修正**:
  過剰は (i) ILES の数値散逸不足 (解像度依存, 実在) + (ii) 観測演算子 (PIVローパス) の複合.
  両メッシュとも実験の2.5-4倍という事実は堅い (=laminarの性質, hex固有でない).
- 限界: カオス脈動を~1周期(24-60フレーム)平均なので, 系統メッシュ依存とサンプリング不確かさは
  完全分離できず. クリーン化には多周期の長時間ラン/アンサンブルが必要.
- 次テスト: (a) CFD に時間・空間平滑を掛けて観測演算子成分を切り分け, (b) 摂動でロックさせた後の
  E が下がるか (組織化が散逸を助けるか).

**観測演算子テスト結果 (7/25, 空間フィルタ): 観測演算子はほぼ無関係 (~4%). 私の第一容疑を棄却.**
- CFD深水帯Eを空間box フィルタ 10→96mm で均しても 2.93x→2.82x (たった4%減). 非現実的な96mm窓でも.
- 理由: laminar CFD は乱流モデルなしで小スケール渦を生成しない → 場が滑らか・大スケール支配 →
  「PIV窓が削る小スケール」がそもそも CFD に無い → 空間フィルタが効かない.
- 含意: E_cfd vs E_piv のギャップは観測演算子でなく**解像された大スケールの実在の差**.
  時間フィルタ(0.1s)も同様に無効なはず (過剰は周期300-370sの遅い脈動 = 0.1sでは削れない. 但し
  5秒データでは直接未検証).
- **問題2 の芯が確定**: E過剰は (i) ILES の散逸不足 (B05のメッシュ依存が示す, 解像度依存, 実在) +
  (ii) 問題1との結合 (無秩序な対称脈動状態は組織化単一渦より大スケールEが高い). R0007(対称でも

**7/24 決定的発見 — 深水帯乖離の正体は自発的対称性の破れ (bistability):**
ユーザーが R0007 だけレジームが違うと指摘 → 符号つき I_circ(t) の時系列で確定 (深水帯 B3+B4):

  run     I_circ平均   |平均|/std  符号反転  正の割合   状態
  R0006   -0.0078      10.3        0%        0%        時計回りに固定
  R0008   +0.0077       9.9        0%       100%       反時計回りに固定 (R0006と真逆!)
  R0007   -0.0017       1.9        4%        3%        弱く時計回り (中途半端なロック)
  C0001   +0.0002       0.19       9%       58%        どちらにも決まらない (対称)

- **R0006 と R0008 は循環の向きが真逆** = 単一ポートのジェットが左右どちらかの壁に付着
  (Coandă) してロックする自発的対称性の破れ. どちらに付くかは微小擾乱で決まる (双安定).
  実験反復は両ブランチ (R0006=CW, R0008=CCW) と弱ロック (R0007) を実現している.
- **CFD (対称メッシュ + laminar) は対称な不安定固定点に留まり, どちらにも commit できない**
  → 高エネルギーの対称脈動流. 「E 過大 + I_circ ~0 + 組織化度 ~0 + 脈動」が全部これで説明される.
- **機構は (b) 対称性破れの欠如が主因**と判明 (先の (a)散逸 vs (b)対称性 の判別). laminar が悪いのは
  散逸だけでなく, 対称メッシュ上で破れの種が無いこと. → **流入に微小非対称摂動を入れるテストが本命の修正**.
- A15 (WALE) の再解釈: WALE の乱流揺らぎが破れの種になれば I_circ が片符号に commit する
  (揺らぎ=トリガー). ならなければ対称のまま → 明示的摂動が必須と確定. どちらでも情報になる.
- **比較方法論の含意 (重要)**: 反復が別ブランチにいるので**符号つき量を反復平均してはいけない**
  (R0006 と R0008 の I_circ を平均すると ~0 になり無意味). 比較すべきは符号不変量:
  |I_asym|, |I_circ|, 組織化度, I_unst. s33 は既に abs(I_circ) を使っており正しい.
- 論文の筋: 「単一ポート inflow は自発的左右対称性の破れ (双安定なジェット付着) を示す. 実験反復は
  両ブランチを実現. 対称 laminar CFD は不安定対称固定点に留まり破れを再現できない → 破れの種
  (摂動/乱流) が単一渦レジーム再現に必須」. これは『CFD が合わない』より遥かに強い物理的発見.
- 補足: R0009 (high) も組織化 (org 0.085-0.151) = 高流量でもロックする. 高流量ほど破れが起きやすい可能性.

**7/24 循環診断 — 深水帯の描像を修正 (I_circ 軸を s33 に追加):**

- **組織化度 |I_circ|/I_rot: CFD ≈ 0.005 (全バンド), 実験は 0.03→0.18 (深水で単一渦に組織化).**
  → CFD の回転活性 (I_rot 高) は左右で相殺し, **単一の渦にまとまらない**.
- **I_circ_cov (循環の脈動): CFD が深水で 1.5-2.6x 高** (脈動は仮説どおり).
- 独立な裏付け: I_asym も CFD 低 (対称), s37 バンド平均場も視覚的に「実験=単一渦 / CFD=中心線ジェット
  +対称的」を示す. **4本の独立な脚 (I_circ, 組織化度, I_asym, 平均場) が同じ結論**を指す.

**検証で捕まえた欠陥 (記録)**: 当初「渦核がさまよう (1.14m)」と報告したが, 直接テスト
(左右半分の滞在 + 二渦対等度) で **渦核検出 (=渦度argmax) がジェット剪断層を拾っていた**と判明
(コヒーレントジェットの最強渦度は渦核でなく両脇の剪断層). 渦核軌跡の具体値は撤回. 本質的結論は
上記クリーン量で保持される. 教訓: 渦度ベースの渦核検出はジェット流では剪断層汚染に注意 → λ2/Q法か
流れ関数極値を使うべき.

**修正後の描像 (確定)**: CFD は「対称・無秩序・脈動する高エネルギー流」(E 高, I_rot 高, I_circ 低,
I_asym 低, 組織化度 ~0) を作る. 実験は「非対称・組織化・安定な単一渦」(I_circ 高, I_asym 高, 組織化度高).
洗濯機の渦 (組織化された単一循環) は**実験側**にあり, CFD はそれを作れていない = 「強すぎる」ではなく
**「まとまらない」**. 機構の精密化: 乱流の欠如が (a) ジェットの散逸不足 に加え (b) 壁付着=対称性破れの
欠如 を生む可能性. **機構 (a) vs (b) の判別は A15 (WALE) が直接行う**: WALE (散逸を足すが対称メッシュは
同じ) で単一渦に組織化+E低下すれば (a) 主因, なお対称のままなら (b)=対称性破れトリガー不足が主因
→ その場合は流入に微小非対称摂動を入れるテストへ.
