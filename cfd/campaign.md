# CFD キャンペーン — 軸別の確定事項 (2026-08-01 全面再構成)

このファイルは「どの軸を振って, 何が確定し, 何が棄却されたか」の正本である.
時系列の実験ノート (発見の順序, 各判定の生の記録) は `cfd/campaign_log.md` に退避した.
ケースごとの数値は `cfd/cases.csv` の verdict 列が正本. 本ファイルは横断整理に徹する.

進め方の原則 (不変): 変更は 1 ケース 1 種類. 判定基準を先に書く. 平均場の渦度マップを必ず見る.

## 0. 現在の立場 (これだけ読めば足りる)

**中心結果**: 3D VOF (interFoam) は, 種 4 種・拡散 4 段階・メッシュ 4 種・流量 2 水準・
乱流モデル 3 種のどれを振っても, 実験の「片壁に付着し盆地を満たす単一渦」ブランチに
入らない. 中央注入では左右対称の二渦, 非対称注入 (P02/P03) ではコンパクトな単一渦に
落ちるが, いずれも壁に付着せず盆地を満たさない (渦度マップで毎回確認済み).

**定量的な言い方** (深水帯 h=0.060-0.098 m):
- 支配符号面積: CFD 50-54% (完全均衡近傍) vs 実験 66%
- ロック強度 |I_circ 平均|/std: CFD 0.03-1.8 vs 実験 12-15. しかも CFD の値は強制振幅に
  比例して増えるだけ (D02) = ロックでなく残差ノイズ
- 偏り指数 (上下エネルギー非対称): 窓平均は CFD -0.065〜+0.162 vs 実験 ±0.24. ただし
  155 s の部分窓に割ると CFD は ±0.27 まで振れて符号反転し, 実験は同じ分割で ±0.007.
  → **CFD は実験規模の非対称を「作れる」が「保持できない」**. 欠けているのは種でも
  振幅でもなく保持機構である.

**実験との一致**: 平均流の大きさ (B03 で 1.16 倍), 充填履歴 h(t) (A00/B03 比較でメッシュ非依存, paper/README.md 記載),
浅水帯レジーム形状, 質量保存 (99.0-100.0%).

**未解明**: 深水帯 E 過剰の機構 (§5), 変動の非単調性 (§5), 数値散逸の実測値 (§7).

### 2.1 種 (摂動) — 「大きさ」が効く. 位置ではない. ただし壁付着はゼロ
- P01 (流入速度に y 方向 5% 傾き): 効かず. I_circ の符号は反転させた = 対称状態が
  ノイズ準位でも強いアトラクタ.
- P02 (流入面の上半分のみ = 面積 1/2 の非対称): **唯一トポロジーを変えた**. 脈動停止
  (10.4%), 定常単一渦. ただし渦はコンパクトで盆地を満たさず (最大塊 50.9 vs 実験 64.5),
  壁に付着しない. 3 指標 (変動/支配符号/最大塊) で全 CFD 中最良.
  注意: これは実験に存在しない非対称を人為的に課した診断プローブであり, モデルではない.
- P04 (ポート開口の 1/11 を壁化, 整流距離ゼロ): 効かず. 完全対称二渦.
- P05 (対称のまま流入面積 1/2 = 速度 2 倍の対照): 脈動はむしろ悪化 (59.9%).
  → P02 の効果は速度でなく**非対称注入そのもの** (交絡分離済み).
- B05 (三角柱メッシュ = 分布した数値非対称): 効かず.
**判定**: 効く種と効かない種の差は位置 (P02 上流 0.6 m vs P04 整流距離ゼロ) ではなく
大きさ (面積 1/2 vs 1/11). 大きな種はトポロジーを単一渦に変えるが, 壁付着と盆地充填は
どの種でも生まれない.

### 2.2 拡散 (移流スキーム + 乱流モデル) — 対称性には完全に不活性
散逸の順に: P08 linear (数値散逸 0) → B03 linearUpwind → P06 RANS → P07 upwind (最大).
- 対称性: 偏り -0.065〜+0.076, 支配符号 50-54% — **全 4 水準で平坦**. 拡散は分岐を
  破らない. むしろ渦粘性は対称解を安定化する (P06/P07 の二渦は laminar より遥かに整然).
  これは粘性理論と整合 (壁付着 = 対称性破れの分岐で, 粘性は閾値を上げる.
  Chen & Jirka 1997: 底面摩擦の増加は Re の減少と等価).
- 変動: **非単調** 19.6 / 48.0 / 21.9 / 17.4% — 両端 (無散逸と最大散逸) が定常で,
  中間の linearUpwind が最も脈動する. 機構は未解明 (§7 に Komen 仮説).
- 平均流: 最も実験に近いのは B03 (linearUpwind) の 1.16x. 定常化した解はすべて過大
  (RANS 2.3x / 中心差分 3.5x / upwind 3.9x) — 蛇行が止まるとエネルギーが平均循環に集中する
  ため. つまり平均流の過大は散逸の単調関数ではなく**レジーム (脈動か定常か) の関数**.
**判定**: 拡散軸は対称性について閉じた. E と変動については新たな問いを開いた (§5, §7).

### 2.3 メッシュ — トポロジーはメッシュ非依存
- P09 (x-y 2 倍, 288 万): 対称二渦のまま. 支配符号 53.1%. ロック強度はむしろ低下 (0.31).
  表面点数 3.83 倍で細分は実効. → **対称二渦は粗メッシュのアーティファクトではない**.
- P10 (z 2.5mm, 138 万): トポロジー不変. 質量欠損 1/12 (副産物として重要).
  偏りの振幅は全 CFD 中最大 (+0.162) かつ持続も最良だが, 実験の安定性には遠い (§3.2).
- B05 (三角柱 181 万): hex と同じ弱組織化/対称.
**判定**: 3 種のトポロジー + 2 方向の細分で不変. メッシュ軸は閉じた.
(ただし「数値散逸の問題ではない」とまでは言えない — §7 の P09 留保を参照)

### 2.4 流量 — CFD と実験は別ブランチにいる (本キャンペーン最重要の定量所見)
- D02 (high 0.75 L/s, 摂動なし): 実験が 4/4 決定論的にロックする条件でも対称二渦.
  符号も逆 (CFD +, 実験 high は 4 本すべて負).
- **ロック強度のスケーリングが決定的**:
```
CFD :  medium 0.67 → high 0.99   (1.48 倍 ≈ 流量比 1.5 = 強制振幅に比例する残差)
実験:  medium 10.6 → high 10.1-13.4 (0.96-1.27 倍 = ほぼ不変 = 飽和 = ロック枝の上)
```
  1.5 倍あたり 1.5 倍しか動かない量で 10 倍の差を埋めるには流量 10 倍が要る.
  → 「もう少しで届く」ではなく**構造的に別の解を選んでいる**.
**判定**: 「medium が遷移域だから失敗する」仮説は棄却. 流量軸は閉じた.
副産物: P09/P10 を medium で回した判断は正当 (流量は効かない).

### 2.5 乱流モデル — WALE は測定限界以下, RANS は §2.2 に含む
- WALE (A15 再開 / B06 フル / P03 種あり): P03 = P02 が E_inst 0.2% 一致 → **WALE の
  効果は測定限界以下と確定**. 機構: 滑らかな場・純剪断で ν_t→0 (設計どおり発火しない).
- B06 vs B03 の 49% 差は WALE でなく脈動解の実現ばらつき (±49%) — 方法論的教訓 (§3.3).

### 2.6 その他の棄却済み交絡

## 3. 指標について学んだこと (2 本目の Methods に書く価値がある)

1. **組織化度 |<ω>|/<|ω|> は「片符号の領域占有率」であって渦の有無ではない** (7/26).
   コンパクトな渦 + 厚い逆符号リングは低い値を返す. 渦の存在は平均場の渦度マップか
   最大同符号連結領域の面積率で見る.
2. **偏り指数は窓平均が保持を隠す** (7/31). B03 の 465 s 平均 +0.076 の内実は
   -0.084/+0.121/+0.271 (155 s 部分窓) の激しい振動で, 瞬時値は実験の +0.249 を超える.
   実験は同じ分割で ±0.007. **平均と持続性 (部分窓 std か自己相関時間) を必ず併記**.
   これを踏まえた正しい記述: CFD は非対称を作れるが保持できない.
3. **脈動解の統計を単一ランで論じない** (7/26). 同設定でも E は ±49% ばらつく
   (B03 vs B06). 定常解は ±0.2% (P02 vs P03). レジームで再現性が桁で違う.
4. **渦度 argmax で渦芯を追わない** (7/24). ジェット剪断層にロックする.
5. **ロック強度の CFD 値は強制振幅に比例する残差** (7/28). 実験のような飽和
   (流量 1.5 倍でほぼ不変, 0.96-1.27 倍) がロックの署名.
6. **平均場の渦度マップを必ず見る**. 数値指標だけで 2 度誤読した (R0007, P02).

## 5. 未決着のもの

1. **問題 2: 深水帯の E 過剰** (E/Up² で 1.9-2.0 倍, E_inst で 2-6.5 倍). 機構未特定.
   確定している内訳: 平均流は 1.16 倍 (B03) でほぼ正しく, 過剰はほぼ全て変動 (9-32 倍).
   新容疑 (§7): linearUpwind の人工的 k 注入 (Komen), 毛管時間刻み違反ノイズ (sigma).
2. **変動の非単調性 → §7.3 で大半が解消**: %の非単調は主に分母 (平均流がスキームで
   3 倍動く) の効果で, 絶対の変動エネルギーでは linearUpwind が最大 (1.3-1.7x) というだけ.
   残る問い「なぜ linearUpwind だけ絶対値でも高いか」には Komen Fig.12 が候補説明.
   §7 の Komen Fig.12 (風上混合が中心差分より k を増やす) が候補説明.
3. **Weigert 2D との矛盾**: あちらは高拡散 ELM が付着し低拡散 EM が直進 (3D と逆).
   semi-Lagrangian の方向バイアス説 / 2D SWE の分岐性質差説. 先方への質問候補.
4. **ポート断面の交換流と alpha 膨張の関係** (7/23 観測). P10 で質量欠損が 1/12 に
   なったことから鉛直解像度が関与. 機構は未詰め.
5. **h/a = 1 の交絡** (7/31 確定): ポート水没と給水路満管が装置設計上同時に起きる.
   実験でも CFD でも分離不能. 両論文に明記必須 (paper/README.md に転記済み).
6. **実験 high (R0009-12) の表面場が未転送** — D02 の偏り/支配符号の直接比較が保留.
7. metrics_primer への §3.2 (偏りの持続性) 追記 — 未実施.
8. 実験側の未確認事項: トレーサ種/粒径, 照明, h≈a の気泡, R0001 の日付.

## 7. 文献照合レビュー (2026-08-01) と次の軸

§9 文献 (Komen 2017 / Schranner 2015 / Deshpande 2012 / Pope 2004, 全て原典 PDF 照合済み)
に照らした設定監査と既存データ照合. **詳細と逐語引用は `cfd/methods_audit.md`**. 要点:

### 7.1 設定監査で判明したこと
- **運動量移流は 12/14 ケースが linearUpwind (風上系)**. Komen Fig.12 は「風上を混ぜると
  純中心差分より k の人工的増加が悪化する」ことを示す (vanLeer での実証. linearUpwind は
  同族だが同一ではない). 我々の P08 (linear) 19.6% vs B03 (linearUpwind) 48.0% は方向として
  整合 — **§5 の「変動の非単調性」に初めて文献の錨が付いた**.
- **毛管時間刻み制約を全ラン破っている**: Deshpande 式(84) (interFoam 較正済み) は
  dz=5mm で dt ≤ 4.2 ms を課すが実測 dt は 17-20 ms (4.7x 違反, P10 は ~11x).
  v2412 interFoam に毛管制限は存在しない (ソース確認済み) ので検知もされない.
  ただし Deshpande 自身が「動く界面では保守的見積もり」と留保.
- **sigma=0.07 は物理を足さずノイズだけ足している**: Bo=126-424, We≈42, 毛管長 2.7mm は
  サブグリッド. Deshpande の重力波検証自体が sigma=0. → **D 系列は sigma=0 を既定に**
  (検証ラン N2 を先行).

### 7.2 P09 の結論の正しい射程
「対称二渦はメッシュ由来ではない」(§2.3) は**「数値散逸の問題ではない」を意味しない**:
細分は ν_num を半減させるだけで, 半減後も閾値より上なら両メッシュとも対称化する.
P08 も Euler 時間積分と Rhie-Chow 減衰は残しており, **数値散逸ゼロのランは存在しない**.
Komen の機構 (pressure strain 過小評価が横方向変動を選択的に潰す) は
「主流ジェットを保ったまま非対称モードだけが消える」我々の症状と同型.
参考: Komen の no-model 格子で ν_num/ν = 0.35-0.60. 我々のメッシュはさらに粗く,
**ν_num/ν > 1 の可能性が十分ある** (WALE が埋もれた説明候補でもある).

### 7.3 Komen 署名の既存データ照合
Komen の署名 (平均速度過大 / 主流 RMS 過大 / 横方向 RMS 過小 / k 過大) を
表面場で照合した結果: **部分一致 — 数値散逸は問題 2 の第一容疑者として維持**.
- 一致 (絶対値): 平均速度 1.8-6.9x, 主流 RMS 2.7-8.0x, k 5-70x
- 相対のみ一致: 横方向 RMS は絶対では過大だが, 異方性比 RMSy/RMSx は CFD 0.72-0.86 <
  実験 0.88 で全ケースが実験より低い = 横方向の相対的抑制 (pressure-strain 機構の向き)
- 追加所見 1: **CFD の変動過剰は遅い蛇行帯に集中** (slow 4.1-11.6x vs fast 1.3-6.3x).
  蛇行は大規模現象なので数値散逸だけでは説明しきれず, 境界条件・幾何は免罪されない.
- 追加所見 2: **「変動%の非単調性」(§5) はほぼ分母の効果と判明**. 絶対の変動エネルギーは
  linearUpwind 0.000415 > central 0.000329 ≈ upwind 0.000319 > RANS 0.000249 と 1.7 倍以内で,
  linearUpwind が最大 (Komen Fig.12 と同方向). %が大きく振れたのは平均流が 3 倍動くため.
- 構造的留保: 比較相手の実験は別ブランチにロックしており RMS 比較にブランチ差が混入する.
  決定打は ν_num の直接測定 (N1).
