### 1.1 運動量移流は全ケース風上系 — Komen の警告に該当する

WS の実ファイルを 14 ケース全て確認した結果 (cases.csv との食い違いなし):

```
ddtSchemes      : Euler                       (全 14 ケース)
div(rhoPhi,U)   : Gauss linearUpwind grad(U)  (12 ケース)
                  Gauss upwind                (P07 のみ)
                  Gauss linear                (P08 のみ)
sigma           : 0.07                        (全 14 ケース)
cap             : maxCo 1.0 / maxAlphaCo 1.0 / maxDeltaT 0.02 (全 14 ケース)
```

**該当する Komen の知見** (Fig.12, p.584-585, PDF 照合済み): no-model チャネル流で
純中心差分 → Van Leer (中心+風上の TVD ブレンド) に替えると, 格子を粗くしたのと同じ
4 傾向が出て, **k の人工的増加はさらに大きくなる**. つまり「風上を混ぜること」自体が
数値散逸の署名を強める.

**我々のデータとの整合**: 変動% は P08 (linear) 19.6 vs B03 (linearUpwind) 48.0 で,
方向として Komen と整合する. これは §5 の未決着だった**変動の非単調性
(19.6/48.0/21.9/17.4) に初めて文献の錨が付いた**ことを意味する — linearUpwind の
分散・散逸の混合が k を人工的に注入している可能性.

留保 2 点: (i) Komen が試したのは vanLeer (TVD ブレンド) で linearUpwind (勾配補正付き
2 次風上) ではない — 同族だが同一ではない. (ii) Komen の機構は乱流帯の話で, 我々の変動は
蛇行帯 (周期 300-370 s). 類推であって直接の実証ではない (§2 の署名照合が判定材料).

### 1.2 時間刻み — 毛管制約を全ラン破っている (ただし帰結には留保)

**質問者の 4.2 ms の検算: 正しい.** Deshpande 式 (84) (p.34, PDF 照合済み) は
```
dt <= max(10*tau_mu, 0.1*tau_rho),   tau_rho = sqrt(rho dx^3 / sigma),  tau_mu = mu dx / sigma
```
で, 定数 C1=0.01, C2=10 は interFoam 自身の静止液滴 ~80 本で較正されたソルバ固有値.
dx=5mm, sigma=0.07 で 0.1·tau_rho = **4.23 ms** — 4.2 ms は正確な値である.
(一般的な Brackbill 4π 形 sqrt(ρΔx³/4πσ) = 11.9 ms より 2.8 倍厳しい. 較正済みの方を採る)

| dx | eq(84) 限界 | 実測 dt 17-20 ms との比 |
|---|---|---|
| 2.5 mm (P10 鉛直) | 1.5 ms | **~11x 違反** |
| 5 mm (鉛直, 大半のラン) | 4.2 ms | **4.7x 違反** |
| 10 mm (水平, ポート近傍) | 12.0 ms | 1.7x 違反 |
| 15 mm (水平, 遠方) | 22.0 ms | 適合 |

**ソース確認**: v2412 の interFoam に毛管時間刻み制限は存在しない
(`applications/solvers/multiphase/VoF/setDeltaT.H` は maxCo/maxAlphaCo/maxDeltaT のみ.
`CapillaryNum` は src 全体で 0 ヒット). つまり**破っていること自体をソルバは検知しない**.

**帰結の留保**: Deshpande 自身が「動く界面では spurious currents は二次的で, この制約は
保守的な見積もり」と明記 (p.27). 違反の実害は界面ノイズ (寄生流) の増幅であって
全体不安定ではない. 対処は dt を 4 ms に落とす (5 倍遅くなる) ことではなく **§1.3 の sigma=0**.

### 1.3 sigma = 0 の採用を推奨する

物理的検討 (数値は検算済み):
```
Bond 数     Bo = rho g L^2 / sigma = 424 (L=a=0.055m) / 126 (L=0.03m)   >> 1
Weber 数    We = rho U^2 L / sigma = 42  (U=0.23, L=0.055)              >> 1
毛管長     l_c = sqrt(sigma/rho g) = 2.7 mm  < 最小セル 2.5-5 mm = サブグリッド
```
表面張力はこの問題で力学的に無視できる量であり, かつ**毛管長がサブグリッドなので
格子は毛管支配の構造をそもそも解像できない** — sigma は物理を足さずノイズ源
(寄生流 + 曲率誤差) と時間刻み制約だけを足している.

**先例**: Deshpande 自身の定在重力波検証が sigma=0 で行われている
(Fig.8 凡例 "Bo=inf (sigma=0 N/m)", PDF 照合済み).

sigma=0 にすると: 毛管 dt 制約が消滅 (§1.2 の違反が定義ごと消える), 寄生流が原理的に
消える, 曲率推定誤差の運動量源が消える. 残る律速は重力波 CFL
(sqrt(gh)·dt/dx ≈ 2.0 @ h=0.1m, dt=20ms, dx=10mm — 陰解法なので安定だが精度の実質律速).

**推奨**: D 系列本番は sigma=0. その前に検証ラン 1 本 (B03 クローン + sigma=0, 5.2h) で
指標への影響と質量保存の変化を定量する (下記 N2).

   機構の向きと整合する弱い証拠.
4. k 過大 — **一致** (k_surf で 5-70 倍. 既知の「変動 9-32 倍」と同じ現象)

追加所見 2 点 (署名照合の副産物として重要):

- **帯域分解: CFD の変動過剰は遅い蛇行帯に集中している**. ジェット帯 slow RMSx は
  CFD 0.0095-0.0198 vs 実験 0.0017-0.0023 = **4.1-11.6 倍**だが, fast は 1.3-6.3 倍に
  留まる (実験の fast には PIV ノイズも混入. 範囲は両実験ランに対する最小-最大). 蛇行 (周期 300-370 s) は大規模現象なので,
  Komen の小スケール機構**だけ**では説明しきれない — 数値散逸が第一容疑者のままでも,
  境界条件・幾何は免罪されない.
- **内部比較 (同一トポロジー同士, ブランチ差の混入なし)**: 絶対の変動エネルギー 2k は
  linearUpwind (B03) 0.000415 > central (P08) 0.000329 ≈ upwind (P07) 0.000319 >
  RANS (P06, E 分解より) 0.000249. linearUpwind が最大 — **Komen Fig.12 の「風上混合が
  k を人工増加」と同方向**. さらに副産物: §5 の「変動%の非単調性」は大半が**分母の効果**

  %の非単調はほぼ見かけであり, 絶対値では「linearUpwind だけが高い」が正しい記述.

構造的な留保: Komen は同一系の DNS と比較するが, 我々の比較相手 (実験) は**別ブランチ
(付着単一渦) にロックした流れ**であり, あらゆる RMS 比較にブランチ差が混入する.
これを消せるのは ν_num の直接測定 (§4 の N1) だけである.

## 3. P09 の結論に対する留保 — 質問者の理解は正しい

**「P09 は『メッシュ解像度の問題ではない』までは言えても『数値散逸の問題ではない』とは
言えていない」— この理解で正しい.** 理由を精密化すると:

1. P09 は Euler + linearUpwind のまま dx だけ半分にした. ν_num ~ u'Δx/2 のオーダー議論では
   細分は ν_num を半減させるが, **半減してもなお分岐の閾値より上にある可能性**は排除
   できない. どのメッシュでも「十分に散逸的」なら, どのメッシュでも対称化する.
2. P08 (中心差分) は移流スキームの散逸をゼロにしたが, **Euler 時間積分 (1 次, 散逸的,
   dt=20ms) と Rhie-Chow 型の圧力-速度結合の減衰は残っている**. 数値散逸ゼロのランは
   本キャンペーンに 1 本も存在しない.
3. Komen の機構 (pressure strain の過小評価が主流成分から横方向成分へのエネルギー再配分を
   選択的に絞る) が正しければ, まさに「主流ジェットを保ったまま非対称モードだけが減衰する」
   という我々の症状と同型である. この機構は解像度を 2 倍にした程度では消えない
   (Komen の q-DNS 9-Grid ですら ν_num/ν ≈ 0.08 残る).
4. よって P09/P08 の正しい要約は「**格子と移流スキームを振っても対称二渦は頑健**」であり,
   「数値散逸は無罪」ではない. 判定には ν_num の実測が要る (§4).

参考の桁 (Komen 結論 p.591, PDF 照合済み): no-model LES 格子で ν_num/ν = 0.35 (30-Grid) /
0.60 (60-Grid), SGS 散逸の 2.4-3.5 倍, 局所では ν_num ≈ ν (60-Grid 中央, Fig.14b).
本研究のメッシュは Komen の 60-Grid より粗いので **ν_num/ν > 1 は十分ありうる**.
これは P03/B06 で WALE が何もしなかったこと (ν_t ≪ ν_num なら埋もれる) の定量的説明候補
でもある.

## 4. Schranner 法による ν_num 実測 — 実装可能 (結論)

原典照合の結果 (詳細は付録 A):
- 必要入力は **連続する 3 時刻の速度と圧力** (式 20/59: t-dt, t, t+dt の中心差分).
  保存済みの 5 s 間隔スナップショットでは足りない → **密書き出しの短い再開ランが必要**.
- **p_rgh がそのまま使える** (再構成不要): バルク水 (alpha≡1) では interFoam の運動量式が
  p_rgh を圧力とする定密度 NSE に厳密に一致し, 重力項も現れない. 定数オフセットは
  収支から脱落する. これは当初懸念 (p_d 問題) の解消である.
- VOF 固有項の回避: 界面圧縮は alpha(1-alpha)=0 でバルクでは不活性. 制御体積を
  水中バルク (alpha>0.999, 界面から複数セルのマージン, 例 z∈[0.01,0.05] @ t=800) に限れば
  未閉包項は現れない. 混入気泡が最大の実務リスク (要 QA: 箱内 min(alpha) 監視).
- 実装計画 (未実行): B03 の t=800 から 1 s, adjustTimeStep off, deltaT 0.02 固定,
  writeControl timeStep / writeInterval 1 → 51 スナップショット (~6 GB, 計算 ~3 分).
  収支は保存済み面フラックス phi と各ケース自身の fvSchemes (fvc) で評価し,
  演算子不一致誤差を抑える (Schranner Appendix A.2: 2 次でも 6 次と 2.8% 一致).
- 制御体積は「十分大きく」(散逸的寄与 > 分散的寄与). 2 箱サイズ x 2 水深で頑健性確認.

**得られるもの**: ν_num/ν の実測値. 「臨界より下にいる」という定性的診断が
「どれだけ下か」になり, 実験と CFD を Chen & Jirka の同じ S 軸に載せられる.
2 本目の Methods の核になる数字.
