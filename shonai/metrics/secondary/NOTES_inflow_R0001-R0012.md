## 再付着長の予測との比較・D′ の判定不能の内訳 (2026-11-02 追記)

### R の水深・時間変化 (`scripts/s39`, `R_m_vs_depth_inflow.png`)
- R は時間 (= 水位) で変化する。h < 0.05 m で長く (低流量・中流量で 1.5〜2 m 近くまで)、h ≥ 0.05 m ではほぼ一定:
  high 1.1 m, medium 1.2 m, low 1.3 m (帯ごとの中央値, 四分位幅 ±0.05 m 程度)。
- 既往研究の基準線 (s39 に追加): Dufresne et al. (2010) R1 = 3.43 ΔB^0.75 b^0.25 = 1.87 m (R/ΔB = 2.0)。
  本実験の ΔB = 0.926 m, b = 0.11 m, SP = L/(ΔB^0.6 b^0.4) = 7.5 > 6.8 で非対称域。
  実測は h ≥ 0.05 m で基準の 60〜70 %、h ≈ 0.035〜0.04 m の浅い側で基準に近づく。
- この式は h/ΔB > 0.8, F ≈ 0.2 の範囲で、水深に依存しない。本実験は h/ΔB = 0.03〜0.11 で範囲外のため、
  形状のみの基準線であって水深込みの予測ではない。Babarutsi et al. (1989) の浅水極限 (L ≈ 1.2 h/c_f) は
  片側拡大・単純チャネル向けで、噴流が入る本形状 (ΔB/b = 8.4) には直接使えない。水深込みの比較は
  深さ平均 2D 計算 (Dufresne 2011 の WOLF 2D と同種) に頼るのが現実的。
- 再付着点の定義が違う (本研究: 壁際 2 行の 30 s 平均 u の符号反転、Dufresne: 染料可視化) ことにも注意。

### D′ の「判定不能」の内訳 (`scripts/s42`, `R00NN_divergence_sign_timeseries.png`)
- 1 フレームの D′ 雑音 σ_noise を、構造関数の lag 0 への外挿で実測した (B2〜B4 の中央値):
  low 約 4e-3, medium 約 7e-3, high 約 1.1e-2, 流出 約 1.8e-3 [1/s]。暫定値の `D_noise` = 5e-3 は
  伝播推定 (1.4e-3) の 3 倍として置いたもので、流入 medium/high の 1 フレームの雑音より小さい。
  1 フレームの符号分類は雑音支配 (σ_total ≈ σ_noise)。
- 時間平均した場に 1 フレーム用の閾値 5e-3 を使うと厳しすぎる。30 s ブロック平均の検出限界は
  3σ_noise/√n = 流入 0.9〜2.0e-3, 流出 0.5〜0.7e-3 [1/s]。s42 はこの限界で面積率の時系列を出す。
- 検出限界を使うと、流入の「判別不能」は 0.7〜0.98 から 0.12〜0.39 に下がる。
- 注意: 領域平均の D′ がほぼ −D_ref に等しい (流入で +0.6〜4e-3, 流出で −0.4〜−2e-3)。PIV の表面 D の領域平均が
  ほぼ 0 で、一様上昇/下降の D_ref (|D_ref| = 0.5〜2.6e-3) が見えていない。D_ref の引き算は検出限界と同程度の
  一様オフセットを D′ に加えることになる。流出 B2〜B4 の「沈み込み 1.0」はこのオフセットが原因で、実際の沈み込みではない。
  D_ref を引かない D で数えると、流出 R0021 の B2〜B4 は 0.99〜1.00 が検出限界以下 (面積平均 D ≈ 1e-4 で、
  限界 6e-4 より十分小さい) = 雑音でなく「ほぼ 0」と言える。
- したがって、前に書いた「湧き上がりの面積が沈み込みの 2〜3 倍」は、D_ref の引き算による一様オフセットの
  影響を含む可能性がある。基準を D_ref にするか D (または領域平均からの偏差) にするかは未決。

## 沈み込み・湧き上がりの「場所」 (2026-11-02 追記 2)

面積率ではなく場所を見るため、セルごとに「30 s ブロック平均の D′ が閾値を超えたブロックの割合」を水深帯別に
マップ化した (`scripts/s43`, `R00NN_divergence_sign_frequency_map.png`)。閾値は max(検出限界, `min_abs_1_s`)。
D_ref 引きの一様オフセット (約 −D_ref) で湧き上がりがほぼ全面に出るため、流入は `min_abs_1_s` = 5e-3、
流出は 2e-3 を加えた。頻度 ≥ 0.8 の連結領域を集中域とし、面積×|D′| の大きい上位 5 個を
`divergence_sign_hotspots.csv` に出す (帯 × 湧き/沈みごと)。

### 流入 (B2〜B4 の集中域を 4×4 の区画で数え、12 ラン中その区画に出たラン数)
- 沈み込み: 壁際に集中。上壁側 (y 1.5〜2 m) の x 0.75〜1.5 m で 12/12、遠端側 (x 2.25〜3 m) で 10/12、
  下壁側 (y 0〜0.5 m) の x 0.75〜1.5 m で 8/12、遠端の角で 9/12。x 0.75〜1.5 m の壁際は
  再付着点 (R ≈ 1.1〜1.3 m) の少し上流側にあたる。port 近傍の隅 (x < 0.75 m, y 0.5〜1.5 m) にも 5/12。
  R0009 ではさらに循環の中心 (1.85, 0.57 m) の沈み込みが全水深帯で最も強い (|D′| 約 0.02〜0.05)。
- 湧き上がり: 噴流の下側から中央にかけて広い。port 近傍〜x 1.5 m までの y 0.5〜1.5 m 帯で 9〜10/12。
  遠端 (x > 2.25 m) は少ない (0〜1/12)。
- 湧き上がりの集中域は沈み込みより数が多く面積も広い。値は D′ 自体の一様オフセットを含むので、
  「多い」ことは場所の傾向として読み、面積の大小比較には使わない。
- low (R0001〜R0004) は集中域が 2〜7 個と少なく、medium・high (13〜15 個、上限 15) と差が大きい。

### 流出 (閾値 2e-3)
- 沈み込みは浅い B1 (h < 0.05 m) だけ。y 0.5〜1.5 m の帯 (port から軸方向) に 12 ラン中 4〜6 ランずつ、
  最大は port のすぐ外側 (x ≈ 0.3 m, y ≈ 1.0 m, R0021 で |D′| 約 0.016) = port への収束位置。
- 湧き上がりの集中域は B1 で 1 個、B2〜B4 では湧き上がり 0、沈み込みも 3 個 (計 12 ラン) だけ。
  流出は水深が増すと D′ が閾値を超える場所自体がほぼなくなる。

## 流速と D′ の関係・流出の表面流速 (2026-11-02 追記 3)

使い捨てのコードで検証した (リポジトリには未保存)。水深帯ごとの時間平均の表面流速と時間平均 D′ を、
マスク後のセルで比べた。

### 「速い所は湧き上がり、遅い所は沈み込み」の検証 (流入 R0001〜R0012)
- 流速と D′ のセル間の Spearman 順位相関は 0.01〜0.29 で、大半が 0.05〜0.15 の弱い正。
- 流速が速い上位 1/3 のセルは、遅い下位 1/3 より D′ が大きい (ほぼ全ラン)。ただし下位 1/3 で D′ < 0 のセルは
  2〜4 割で、遅い所の大半は D′ がほぼ 0 (D_ref 引きの一様オフセットで少し正側)。沈み込みではない。
- |D′| > 5e-3 のセルの流速 (バンド中央値に対する倍率の中央値, B2〜B4, 12 ラン): 湧き上がり 1.36 倍,
  沈み込み 1.22 倍, それ以外 0.97 倍。湧き上がりも沈み込みも平均より速い所に出る。high では 1.0〜1.2 倍でほぼ差がない。
- 発散は速度の空間変化で、強い収束・発散は速度勾配のある場所 (噴流の縁、壁沿いの流れ、渦の縁) に出る。
  遅い所は符号によらず |D′| が小さい。したがって「遅い所が沈み込み」は支持されない。
- 時間平均値どうしの比較で、時間変化は見ていない。D_ref 引きのオフセットを含む。

### 流出の表面流速
- 水深 0.05〜0.10 m のフレーム平均流速 (`frame_metrics` の `mean_speed` の中央値):
  流入 low 約 8 mm/s, medium 約 16 mm/s, high 約 30 mm/s に対し、流出は R0013〜R0020 で約 0.3 mm/s,
  R0021〜R0024 で約 0.5 mm/s。流入の約 1/20〜1/100 で、PIV ノイズ (σ_u ≈ 3e-4 m/s 程度) と同じ大きさ。
- そのため流出の D′ は 1 フレームで検出できず、時間平均でも閾値 (2e-3 [1/s]) を超えるのは浅い B1 の
  port のすぐ外側だけ (前節)。R は流出では定義できない (噴流がない)。
- 他の主要指標 (E, φ_lv, I_asym) が流出で成り立つかは未確認。流速が同じ大きさなのでノイズの影響は受ける見込み。
- 流出で示せそうなもの: 長時間平均した速度場・渦度場, B1 の port 近傍の収束, 3D/深さ平均 2D CFD との比較。

## 「ほぼ 0」と「検出不可能」の区別 (2026-11-02 追記 4)

D′ は D_ref 引きのまま (変更なし)。判定不能だったセルを 2 つに分けて表示する (`s42`, `s43`)。
ε = 5e-3 [1/s] (up/down と数える最小の |D′|, 全ラン共通)、limit = 3σ_noise/√n (30 s ブロック平均の検出限界)。
- 湧き上がり / 沈み込み: |D′| > max(limit, ε)。
- ほぼ 0 (確認済み): |D′| + limit ≤ ε。ブロック平均の ±limit の区間が ±ε の内側に収まり、|D′| < ε と言える。
  厳密な 0 ではなく「ε 未満」の意味。
- 検出不可能: 上のどれでもないセル。雑音の限界が大きく、|D′| < ε と確認できず、かつ ε を超えてもいない。
  limit ≥ ε なら「ほぼ 0」は成立せず、up/down 以外はすべて検出不可能 (雑音支配)。
- 水深帯別の面積率 (30 s ブロックの平均, 流量グループ平均) 〔up / down / ほぼ 0 / 検出不可能〕:
  - 流入 low B1 0.12 / 0.06 / 0.74 / 0.07, B4 0.07 / 0.05 / 0.81 / 0.06
  - 流入 medium B1 0.23 / 0.10 / 0.56 / 0.11, B4 0.11 / 0.05 / 0.73 / 0.10
  - 流入 high B1 0.38 / 0.19 / 0.31 / 0.13, B4 0.23 / 0.08 / 0.51 / 0.19
  - 流出 (low〜high とも) B2〜B4 は ほぼ 0 が 1.00、B1 も 0.97〜1.00 (high の B1 のみ 沈み込み 0.02)
- つまり以前の「判定不能」の大半は、雑音で見えないのではなく、|D′| が ε 未満と確認できた「小さい」領域だった。
  検出不可能は流入で 0.06〜0.19、流出で 0〜0.01 と少ない。流入 high で深いほど検出不可能が増える (σ_noise が大きいため)。
- 注意: 「ほぼ 0」は ε の選び方に依存する。流出の D′ は約 −D_ref (−0.4〜−2.6e-3) の一様なずれに乗っており、
  ε を 2e-3 まで下げると流出の一部は「ほぼ 0」でなくなる。ε = 5e-3 は暫定。
- 図 (`R00NN_divergence_sign_timeseries.png`, `R00NN_divergence_sign_frequency_map.png`) は 24 ラン分を作り直した。
  `divergence_sign_blocks.csv` の列は f_up, f_down, f_zero, f_undet (旧 f_below は廃止)。

## 再付着長: 付着側を先に決める方式へ変更 (2026-11-02 追記 5)

旧: 両壁で再付着点を探し、短い方を R_m とした。両壁で同時に見つかるフレームは 0〜9 % しかなく、
そこでは付着していない壁の短い交差 (偽の再付着) が選ばれ、付着側が頻繁に切り替わっていた (最大 56 回)。

新 (`compute_reattachment_length`, `side_mode = 'jet_axis'`, 既定):
- 付着側は R と無関係な量、噴流軸の横位置で先に決める。軸 = x 0.6〜1.0 m で平均した u (30 s 窓平均) が
  最大になる y。軸が盆地中心線 (y = 0.981 m) から 0.05 m 以上上なら ymax、下なら ymin、
  0.05 m 以内なら対称型として "none" (R_m = NaN)。
- R_m は付着側の壁だけの再付着長。反対側の壁の交差は `R_other_m` に別記録 (R_m に混ぜない)。
  `R_ymin_m`, `R_ymax_m` は従来どおり両方残す。`R_side` は付着側 (交差が見つからなくても付着側を示す)。
  `jet_axis_y_m` を追加。旧方式は `side_mode = 'min'` で使える。
- 検証: 噴流軸の側は、再付着が求まった全ランで旧方式の支配的な側 (R0005, R0006, R0009〜R0012 = ymax,
  R0001, R0003, R0004, R0008 = ymin) と一致した。軸が中央付近のランは R0002 (y 0.95 m) と R0007 (1.02 m)。
- 再計算 (流入 R0001〜R0012) の結果:
  - 付着側の切り替え回数は全ランで 0 (旧 0〜56 回)。
  - 水深帯ごとの R_m の中央値はほぼ変わらない (差 0.01 m 前後, 最大でも R0011 の B1 で 1.12 → 1.20 m)。
  - R が求まるフレームの割合: R0002 0.15 → 0.01, R0007 0.11 → 0.08, R0011 0.81 → 0.77, 他はほぼ同じ。
    R0003 は 0.44 のまま (43 % のフレームが軸の不感帯で "none")。R0003 B1 の R_m は 0.63 m → NaN。
  - R0009 の t = 158〜209 s の「ymin 側 R ≈ 0.64 m」は、R_m (1.12 m) には入らず `R_other_m` (中央値 0.64 m) に
