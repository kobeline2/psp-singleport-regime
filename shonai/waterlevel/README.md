# waterlevel — 上池・下池の水位から見る流量(2回の実験)

shonai の水位ログ解析。`doc/qdip_jet_check.md` の問い(上池の水位から出した流量の谷は、実際の流量低下か)に対し、
下池の水位計という 2 つ目の独立な水位記録で答える。流量の出し方は先生の方法(`scripts/checks/qdip_jet_check.py`、
`doc/metrics_primer.md`、s31/s33)に合わせた(コードの流用ではなく、同じ式の再実装)。

## 入力(リポジトリの外に置く)

2 回の実験それぞれ、inflow / outflow の 4 ファイル。

| | 形式 |
|---|---|
| 上池 | UTF-16 のタブ区切り(No. / Date / mm:ss.s / 水位 mm、0.3 s)。時刻に「時」が無い |
| 下池 | Keyence NR-500 の CSV(CP932、0.1 s)。ヘッダーにスケーリング(計測値1/2 → 表示値1/2) |

## 実行

```bash
python3 shonai/waterlevel/wl_flow_analysis.py --label run1 --lower-valid-mm 125 \
    --upper-inflow U_in.csv --upper-outflow U_out.csv --lower-inflow L_in.CSV --lower-outflow L_out.CSV
```

- `--lower-valid-mm`: 下池の水位計がこの水位以下の読みを使わない。1 回目(10/24)は 125、2 回目(10/25)は 120 を使った。省略時は最低読み + 40 mm。
- `--lower-area` / `--lower-area-range`: 下池の平面積 [m²](既定 1.63 / 1.63〜1.89)。**未確定**(下記)。
- 出力先は `local/derived/qc/waterlevel_two_basin/<label>/`(gitignore 済み)。必要: Python 3.8 以上、numpy、matplotlib。

出力: `levels_aligned.png`(上池 30〜100 mm の記録に下池を時刻合わせ)、`discharge_aligned.png`(Q(t))、
`lower_level_linearity.png`(下池が定速で動いたか)、`window_Q.csv`(水深 6 mm 窓ごとの Q)、
`band_transit_Q.csv`(B1〜B4 の通過時間法)、`dwell_Q_upper.csv`(滞在時間法)。

## 方法の要点

- 時刻合わせ: t = 0 は上池の記録開始(inflow は 30 mm、outflow は 100 mm)。下池の記録をその期間に切る。2 台のロガーの時計は合っているものとして扱う。
- 上池の流量: 先生と同じ。滞在時間法(5 mm 窓)、通過時間法(B1〜B4、B1/B2 には導水路の面積 0.6·b を加える)、A_plan = 5.7918 m²。
- 下池の流量: A_low × |dh/dt|。dh/dt は水位の区間平均の差(0.1〜0.3 s 刻みのログでは、移動平均の勾配だと窓の両端しか効かずノイズが大きいため)。

## 結果(2026-10-24、10-25 の 2 回)

- ポンプの送水量(下池の水位から)は一定。下池の水位は直線的に変化(R² > 0.998)、60 秒ごとの傾きのばらつきは 3〜5%。
  約 15〜20% 以下の変化は検出できない。送水量の低下は検出されなかった。
- 上池の水位から出した流量は、浅い水深で凹む(2 回目 inflow: 上池 37〜41 mm で約 0.36 L/s、53 mm で約 0.22 L/s。1 回目は 37 mm で約 0.40 L/s)。
  同じ時刻の下池由来は 0.6〜0.7 L/s(2 回目)で一定なので、上池由来の凹みは送水量の低下ではない。
  outflow は 50〜54 mm で約 0.53 L/s、2 回でほぼ重なる。深い水深(75 mm 以上)では上池由来が 0.75〜0.9 L/s と設定を上回る。
- 先生の PIV 検証(噴流の表面速度が谷に追従しない、12 本中 5 本)と同じ向きの結果。今回の 2 回の PIV は未検定。
- 谷の要因は未特定: 上池の水位計(導水路と対向する短辺の角)の読み、または水槽側・配管側の水の行き先。
  動画では、水深 3 cm 付近でパイプからの水が整流板に当たり、流入口付近の水位が一時的に上がる(跳水に近い変化)。気泡もパイプ近くに集まる。
  これは導水路・ポート付近の局所的な現象で、角の水位計は直接読まない。

## 注意

- 下池の水位計は、センサー出力が 4-20 mA の上限(20 mA)で飽和する。飽和する水位は 1 回目で約 111 mm、2 回目で約 78 mm
  (ロガーのスケーリングが回ごとに違うため)。飽和付近の読みは使えない。どちらのスケーリングが正しいかは未確認。
- 下池の平面積は未確定: 水位の傾きの比から約 1.63 m²、図面からの換算で約 1.89 m²(ポンプ分を引く前)。下池由来の絶対値はこの幅で動く。
  「下池は一定」という結論は、面積に依らない。
