## 2. なぜ「ただの 2D/3D 比較」ではないのか

今週こちらで確定した発見:

- 実験の medium 4 反復は**同じ条件なのに循環の向きが違う** (R0005/R0006 = 一方の壁, R0008 = 逆,
  R0007 = 対称のまま). 単一ポート流れは自発的に左右対称性を破る**多安定系**.
- 3D laminar VOF (OpenFOAM) は**対称状態から動かない**. 流入に 5% の横速度バイアスを与えても
  ロックしなかった (P01). 現在, 強い幾何非対称 (流入の上半分のみ注入) で判定中 (P02).

Weigert のレポートを読むと, **彼のメッシュ感度解析 (P1-P14) が事実上, 同じ現象の数値実験**になっている:

| 彼の設定 | 結果 | こちらの対応物 |
|---|---|---|
| 対称メッシュ (5.0/4.0/2.5/2.0 cm, breakline付き3.0) | ジェット直進・対称 | 我々の 3D 対称CFD / 実験 R0007 |
| 非対称メッシュ (4.5/3.5/3.0/1.5/1.0/0.5 cm) | 偏向 + 単一渦がロック | 実験 R0005/R0006/R0008 |
| 偏向の向き | culvert 縁でセルの重なりが小さい側へ一貫 (P13 は左, P11/P14 は右) | 別ブランチの実現 |
| breakline で対称化 (P8) | 渦が消える | 種を消すと対称に戻る |

彼自身, レポート最終ページで「完全に対称な系でなぜ渦が生じるのか」と問うている. こちらが
R0006/R0008 の逆回転から立てた問いと同じ. **偶然, 同じ物理に別方向から到達している.**

### そこから出てくる新しい問い: 感受性の階層

```
2D SWE-ELM   : 数値誤差レベルの非対称 (セルの重なりの差) だけで破れる  ← 最も敏感
実験          : 物理的な微小擾乱で破れる (通常は破れる, たまに R0007 のように破れない)
3D laminar VOF: 5% の明示的摂動でも破れない                          ← 最も鈍感
```

なぜこの順序になるのか, が論文の芯になりうる. 仮説:
**破れた状態を「安定化」するには散逸が要る**. SWE-ELM は semi-Lagrangian 移流で数値拡散が強く,
一度傾いた流れを単一渦として固定できる. 一方 3D laminar は乱流散逸を持たないため, 対称な
不安定固定点の周りで高エネルギーの脈動を続け, どちらにも落ち着けない.
- 傍証: 彼の solver 比較で**低拡散の SWE-EM は直進のまま** (= こちらの 3D 対称CFDと同じ挙動).
- 傍証: こちらの WALE テスト (A15) では窓が短く効果が出なかったが, 方向としては同じ論点.

## 3. 相補関係 (どちらが何を担当できるか)

| 論点 | 2D SWE (HEC-RAS) | 3D VOF (OpenFOAM) |
|---|---|---|
| 計算コスト | 分オーダー | 時間オーダー (現行 5 h/1000 s) |
| 対称性破れ | 数値非対称で容易にロック | 対称のまま (摂動に鈍感) |
| h/a ≈ 1 の遷移 | **構造的に扱えない** (満管⇔自由表面. storage area が圧力を持てない. 排水時 5-6 cm で振動的に破綻) | VOF で解ける (気泡パージまで再現) |
| 鉛直構造 | 深さ平均のみ | 解像 (ジェットの貫入・剪断層) |
| 排水の履歴依存 | 単独 turbine は無構造, pump→turbine 連続でのみ一致 | 未実施 (E 系列の設計に直結する教訓) |
| 質量収支 | 注水 0.03% / 排水 5-14% | 100.0% (v1 設定) |

**要点**: 2D は安い・敏感・h/a≈1 で破綻. 3D は高い・鈍感・遷移を解ける. 補い合っている.

## 4. 先方に伝えるべき実務事項 (最重要)

**彼のモデルは Shonai 2025 (旧版) の実験条件で較正されている.** 現行の実験データは
やり直したもので, 以下が異なる:

1. **バンド定義**: 旧 = 3.0-4.5 / 4.5-6.0 / 6.0-7.5 / 7.5-9.0 cm (等間隔4分割)
   → 現行 = 30-50 / 50-60 / 60-75 / 75-100 mm (h/a 基準で B2 を遷移帯として細かく取る)
2. **流量**: 旧 = 0.23 / 0.36 / 0.63 l/s (inflow) 等
   → 現行 = 0.25 / 0.50 / 0.75 l/s. ただしこれは**公称ラベル** (この目標にポンプを調整した値)
   であり実測平均ではない. 実流量は走行中に変動する (バンド透過時間から逆算すると
   B1 ~0.29 → B4 ~0.57 l/s とランプする例を確認).
3. **初期水位**: 旧レポート記載「注水は 2.0 cm から開始」→ **実際の実験は 0 mm (乾いた床) から開始**.
   PIV 記録は 30 mm 到達時点から. つまり彼のモデルは初期条件が実験と異なり,
   スピンアップ履歴が短い (この点はこちらの 3D CFD でも同じ課題を抱えている).

伝え方: 批判ではなく「こちらの実験プロトコルが更新されたので, 比較の前に条件を揃えたい」という形で.
彼のレポート自体の価値 (メッシュ感度・solver 比較・inlet 表現の知見) は条件更新後も残る.
