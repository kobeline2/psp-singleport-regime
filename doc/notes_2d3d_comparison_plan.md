## 0. 既存メモとの食い違い (要確認)

Weigert の Table 3-1 は「幅/セル数が整数なら対称メッシュ」とし, 1.0 / 0.5 cm を対称側に分類している.
`notes_2d3d_collaboration.md` §2 は 1.0 / 0.5 cm を非対称メッシュ側に置いている.

- 実際は非対称 → 「2D はメッシュの偏りだけで破れる」という既存の整理のまま.
- 本当に対称 → 2D が丸め誤差や semi-Lagrangian 補間の非対称で**自発的に破れている**ことになり,
  3 本目の論点が変わる.
- 決め手: HEC-RAS のセル面座標と culvert 中心線の位置 (先方のプロジェクト/.hdf が必要).

## 1. 条件の不一致 (比較以前)

| 項目 | Weigert 2D | 3D (cases.csv) | 現行実験 |
|---|---|---|---|
| 流量 [L/s] | 0.23 / 0.36 / 0.63 | 0.5 (B03), 0.75 (D02) | 0.25 / 0.5 / 0.75 (公称) |
| 流入口の高さ | culvert rise 0.055 m | 注入面 z<0.02 m (44 面) | ポート 0.055 m |
| 流入口の幅 | 4 barrel x 0.024375 = 0.0975 m [要確認] | 0.11 m | 0.11 m |
| 平面寸法 | 公称 3.0 x 2.0 m | 公称 3.0 x 2.0 m | 実測 2.952 x 1.962 m |
| 水位範囲 | 2 → 9 cm | 20 → 約 102 mm (1000 s) | 同左 |

- 流量の重なりが無い. 2D は分オーダーなので **2D を 0.5 / 0.75 L/s で再計算**するのが安上がり.
- [推論] 3D の注入速度は P01 の U=0.2273 m/s = 0.5 L/s / (0.11 x 0.02 m) と一致.
  実機ポート (高さ 55 mm) なら約 0.083 m/s. **3D の運動量束は実機の約 2.75 倍で水位に依らず一定**.
  2D は Q/(w h) で水位とともに低下する (Weigert P22 の記述). 3 者のジェット強度の履歴が違う.
- 実測寸法は公称より平面積が 3.6% 小さい (AGENTS.md). 流量・正規化は実測値で.
- Weigert のモデルは旧版 (Shonai 2025) 条件で較正されている (バンド・流量が現行と違う).
- Weigert の複合運転の待機は一律 40 分. 実験は低・中 22 分, 高 60 分 [事実: S.4 と S.16].

## 2. 観測演算子を揃える

- PIV = 表面速度, 2D = 深さ平均, 3D = 任意の層. 層流放物線分布なら表面 ≈ 平均の 1.5 倍.
  3D の平均流が実験の 1.16 倍という結果にも換算が混じる可能性 [要確認].
- Weigert の R スクリプトは速度の大きさの時間平均 + 空間平均 + bilinear + 3x3 平滑化.
  repo の `import_cfd_surface.m` → s30 系とは処理が違う.
- 方針: HEC-RAS の .hdf を canonical `piv` 構造体に落とし, 実験・3D と同じ s30–s33 に通す
  (AGENTS.md: インポート後はツール非依存).
- バンド定義 (旧: 等間隔 4 分割 / 現行: 30-50, 50-60, 60-75, 75-100 mm), Ω マスク, 5 cm 格子を共通化.

## 3. 比較軸の候補 (物理)

1. **分岐図上の位置**: 各モデルの実効 c_f を (Chen & Jirka の S, Dewals の R) の軸に載せる.
   2D の Manning n=0.011 は h=5 cm で c_f ≈ 3e-3 (概算). 3D 層流の c_f ≈ 3 nu/(U h) も桁は同じ (粗い概算).
   ただし Manning 則は乱流粗面の式で, 3D 層流とは摩擦の法則自体が違う.
2. **3D の深さ平均で SWE が落とす項を見積もる**: 鉛直シア由来の分散項, ジェット近傍の非静水圧.
3. **3D で 2D の校正値を決める**: ポート前後の損失係数, 水頭-流量関係 (h/a≈1 付近).
   Weigert の culvert n=0.12 (計算を通すための値) を根拠ある値に置換できるか.
4. **3D のメッシュ半セルずらし**: Weigert の非対称メッシュに相当する弱い種 (P04 の 1 セル閉塞より弱い).
5. **水平解像度の対応**: 3D は 10–15 mm, Weigert は 10 mm. P09 (細分) と Weigert 0.5 cm (P14) を並べる.
6. **履歴依存 (最重要)**: 「静止から排水」と「ポンプ終了状態から排水」を 3D で比較 (E 系列).
   残留循環が単独タービンの失敗を説明するという仮説の検証.
7. **h/a≈1 の遷移**: 2D は構造的に扱えない (storage area が圧力を持てない). 3D で 5–6 cm の挙動を見る.
8. **コスト対精度**: 2D は分, 3D は約 5 h / 1000 s. 質量収支は 2D 排水 5–14%, 3D 100%.

## 4. 統計的扱い (双安定系)

- 同条件で向きが割れる (medium) ので, 単一ランの場の比較は意味が薄い.
- 向きに依存しない量で比較: |I_circ|, 片符号領域の占有率, ロック強度.
- 2D はメッシュずらし・微小擾乱の集団統計を取り, 3D (少数ラン) がその分布のどこに入るかを見る.
- 鏡像テスト (メッシュを反転して結果が反転するか) で 2D の数値非対称が solver 由来かを切り分ける.

## 5. 先方への依頼候補 / 未解決

- HEC-RAS プロジェクト一式と .hdf 出力, R スクリプト (§0 の確認に必須).
- 現行条件 (0.5 / 0.75 L/s, 現行バンド) での再計算.
- 未解決の矛盾 (`paper/README.md` 3 本目): 2D は高拡散の ELM が付着し低拡散の EM が直進したが,
  3D は拡散を足すほど対称が安定化した. ELM の付着が拡散ではなく補間の方向バイアス由来の可能性.
